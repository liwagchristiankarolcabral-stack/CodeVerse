Responsive web design

Responsive Web Design (RWD) is an approach to creating websites that display and function effectively on different screen sizes and resolutions.

A responsive website automatically adjusts its layout, text, images, and other elements to provide a suitable experience on mobile phones, tablets, laptops, and desktop computers.

Learning Objectives

  • Understand responsive web design and its importance.
  • Learn how CSS media queries control responsive styles.
  • Understand mobile-first design and breakpoints.
  • Use Flexbox and CSS Grid for flexible layouts.
  • Make images, videos, and typography responsive.
  • Understand the purpose of the viewport meta tag.

Precursor to responsive design: mobile web design

Before responsive web design became widely adopted, developers often created separate website experiences for desktop and mobile users.

These approaches were commonly called mobile web design, mobile web development, or mobile-friendly design. Their goal was to make websites usable on devices with different screen sizes, resolutions, and performance capabilities.

Early Mobile Web Development

Earlier mobile devices had limited processing power, memory, bandwidth, and browser capabilities. Some devices supported only simplified web content.

Developers sometimes used browser detection on the server to deliver different website versions depending on the device being used.

Modern Mobile Web Development

Modern smartphones and tablets can support many of the same web technologies as desktop computers. As a result, developers can create one flexible website that works across multiple devices.

Important Considerations

  • Screen size and resolution
  • Device processing capabilities
  • Internet connection and bandwidth
  • Battery consumption
  • Content accessibility and usability
  • Touchscreen interaction

Responsive design considers not only the size of the screen but also the needs and experience of the people using the website.

Introducing responsive web design

HTML content naturally adjusts to the available width of the browser when no restrictive CSS layout rules are applied.

However, adding fixed-width containers, large images, or rigid multi-column layouts can create problems when a webpage is displayed on smaller screens.

Problems with Fixed-Width Layouts

  • Content may extend beyond the screen.
  • Horizontal scrolling may become necessary.
  • Text columns may become too narrow to read.
  • Large screens may display excessive empty space.
  • Images and other media may overflow their containers.

Fixed-Width Layout Example

.fixed-container {
    width: 1000px;
    margin: 0 auto;
}

This container always attempts to occupy 1000 pixels of width. On a narrow screen, it can cause horizontal overflow.

Responsive Layout Example

.responsive-container {
    width: 100%;
    max-width: 1000px;
    margin: 0 auto;
    padding: 20px;
}

The responsive container can shrink with the available space while limiting its maximum width.

History of Responsive Web Design

The term responsive web design was introduced by Ethan Marcotte in 2010.

The original approach emphasized three important techniques:

  • Fluid Grids: Layouts that adjust to available space.
  • Flexible Images: Images that fit within their containers.
  • Media Queries: CSS rules applied under selected conditions.

Flexible Image Example

.responsive-image {
    max-width: 100%;
    height: auto;
}

This allows an image to shrink when necessary without stretching it beyond its original dimensions through the max-width rule.

Responsive web design is not a separate programming language. It is a collection of techniques and practices used to make websites adapt to different viewing environments.

Media Queries

CSS media queries allow developers to apply specific styles when certain conditions are met.

These conditions can include viewport width, screen characteristics, and the type of media displaying the document.

Basic Media Query Syntax

@media screen and (min-width: 800px) {
    .example-container {
        padding: 30px;
    }
}

In this example, the padding rule is applied when the document is displayed on a screen with a viewport width of at least 800 pixels.

Responsive Background Example

.example-box {
    background-color: lightblue;
    padding: 20px;
}

@media screen and (max-width: 600px) {
    .example-box {
        background-color: lightgreen;
    }
}

The background becomes light green when the viewport width is 600 pixels or less.

Breakpoints

A breakpoint is a point at which a responsive layout changes because a media query condition becomes true or false.

Breakpoints are commonly used to change column arrangements, navigation menus, spacing, and typography.

Breakpoint Example

.demo-layout {
    display: grid;
    grid-template-columns: 1fr;
}

@media (min-width: 768px) {
    .demo-layout {
        grid-template-columns: 1fr 1fr;
    }
}

@media (min-width: 1200px) {
    .demo-layout {
        grid-template-columns: repeat(3, 1fr);
    }
}

This example uses one column by default, two columns on wider screens, and three columns when more space becomes available.

Breakpoints should be chosen according to when the content needs a layout adjustment, rather than only targeting specific devices. Relative units can also be useful for breakpoints.

Mobile-first design

Mobile-first design is a responsive development approach that begins with a simple layout suitable for smaller screens.

Additional styles are then introduced for larger viewports using media queries.

Mobile-First CSS Example

.demo-content {
    display: flex;
    flex-direction: column;
    gap: 15px;
}

@media (min-width: 768px) {
    .demo-content {
        flex-direction: row;
    }
}

Example Explained

  • Small screens use a vertical arrangement.
  • Larger screens use a horizontal arrangement.
  • The basic layout works without a media query.
  • Additional screen space is used when available.

Media queries are useful for responsive design, but not every responsive layout requires them. Flexible sizing and modern layout methods can adapt automatically in many situations.

Responsive layout technologies

Modern CSS provides several layout systems that make responsive website development easier.

Instead of creating a separate layout for every possible screen size, developers can use flexible containers that adjust to the available space.

Common Responsive Layout Technologies

  • CSS Flexbox
  • CSS Grid
  • Flexible sizing units
  • Media queries
  • Minimum and maximum sizing constraints

Flexbox and Grid are particularly useful because they provide built-in mechanisms for distributing available space.

Flexbox

CSS Flexbox is a one-dimensional layout system used to arrange elements along a row or column.

Flex items can grow or shrink depending on the space available inside their container.

Basic Flexbox Example

.demo-flex-container {
    display: flex;
    gap: 15px;
}

.demo-flex-item {
    flex: 1;
}

The flex: 1 shorthand allows the items to share the available space in the flex container.

Responsive Flexbox with Media Queries

.demo-flex-wrapper {
    display: block;
}

.demo-flex-col1,
.demo-flex-col2 {
    padding: 20px;
}

@media screen and (min-width: 600px) {
    .demo-flex-wrapper {
        display: flex;
        gap: 5%;
    }

    .demo-flex-col1 {
        flex: 1;
    }

    .demo-flex-col2 {
        flex: 2;
    }
}

HTML Example

<div class="demo-flex-wrapper">

    <div class="demo-flex-col1">
        <h3>Column One</h3>
        <p>First column content.</p>
    </div>

    <div class="demo-flex-col2">
        <h3>Column Two</h3>
        <p>Second column content.</p>
    </div>

</div>

Example Explained

Below 600 pixels, the two content sections follow the normal vertical document flow.

At 600 pixels and above, Flexbox places them side by side. The second column receives approximately twice the flexible space of the first column.

CSS grid

CSS Grid is a two-dimensional layout system that organizes elements into rows and columns.

Grid provides flexible track sizing and precise control over the placement of webpage elements.

The fr Unit

The fr unit represents a fraction of the available space in a grid container. 

.demo-grid-container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
}

This creates three equally sized grid columns.

Responsive Grid Example

.demo-grid-wrapper {
    display: block;
}

@media screen and (min-width: 600px) {
    .demo-grid-wrapper {
        display: grid;
        grid-template-columns: 1fr 2fr;
        column-gap: 5%;
    }
}

HTML Example

<div class="demo-grid-wrapper">

    <div>
        <h3>Sidebar</h3>
        <p>Related information.</p>
    </div>

    <div>
        <h3>Main Content</h3>
        <p>Primary webpage content.</p>
    </div>

</div>

Example Explained

On narrow screens, the content is arranged vertically.

When the viewport reaches 600 pixels, CSS Grid creates two columns with a 1:2 fractional track ratio.

Grid is useful when developers need coordinated row and column layouts, while Flexbox is often convenient for arranging items along one axis.

Responsive images/media

Images and other media should adapt to the available space without extending beyond their containing elements.

Responsive Media Example

.demo-media img,
.demo-media picture,
.demo-media video {
    max-width: 100%;
}

The max-width: 100% declaration helps prevent media elements from becoming wider than their containers.

Responsive Image Example

<img
    src="images/website.jpg"
    alt="Website design example"
    class="demo-responsive-image"
>
.demo-responsive-image {
    max-width: 100%;
    height: auto;
}

Why Image Optimization Matters

Downloading an unnecessarily large image on a mobile device can waste bandwidth and slow down page loading.

Images should be optimized for their intended display sizes and formats.

Responsive Image Techniques

  • max-width: Prevents images from exceeding container width.
  • srcset: Provides alternative image resources.
  • sizes: Describes expected image display sizes.
  • picture: Allows different image sources under selected conditions.

Example Using srcset

<img
    src="images/photo-800.jpg"
    srcset="
        images/photo-400.jpg 400w,
        images/photo-800.jpg 800w,
        images/photo-1200.jpg 1200w
    "
    sizes="
        (max-width: 600px) 100vw,
        50vw
    "
    alt="Responsive example image"
>

The browser can select an appropriate image resource based on the available information, including the viewport and display density.

Additional Media Considerations

  • Choose appropriate image formats such as JPG or PNG.
  • Compress images to reduce download sizes.
  • Use CSS gradients and shadows when suitable.
  • Provide appropriate video or audio sources for different devices.

Responsive typography

Responsive typography adjusts text presentation to make content readable across different screen sizes.

Headings that appear suitable on a large desktop monitor may be too large on a small mobile screen.

Developers can use media queries, relative units, and CSS calculations to create flexible typography.

Using media queries for responsive typography

Media queries can change font sizes according to the width of the viewport.

Responsive Heading Example

.demo-responsive-heading {
    font-size: 2rem;
}

@media (min-width: 1200px) {
    .demo-responsive-heading {
        font-size: 4rem;
    }
}

Example Explained

  • Smaller screens use a heading size of 2rem.
  • At 1200 pixels and above, the heading uses 4rem.
  • The rem unit is relative to the root element's font size.

Media queries can also adjust spacing, alignment, line lengths, and other presentation properties.

Using viewport units for responsive typography

Viewport units allow CSS values to respond directly to the dimensions of the browser viewport.

The vw unit represents one percent of the viewport width.

Viewport Unit Example

.demo-viewport-heading {
    font-size: 6vw;
}

This heading size changes continuously as the viewport width changes.

Accessibility Consideration

Using viewport units alone for text can interfere with text-only zoom behavior. Combining relative font units with viewport units is a better approach.

Using calc()

.demo-fluid-heading {
    font-size: calc(1.5rem + 4vw);
}

The calc() function combines a relative font size with a viewport-based value to create fluid typography.

Benefits of Fluid Typography

  • Font sizes can change gradually with the viewport.
  • Fewer typography-specific breakpoints may be needed.
  • Relative font sizing helps preserve text scalability.

The viewport meta tag

The viewport meta tag tells mobile browsers how to size the viewport when displaying a webpage.

It is usually placed inside the <head> section of an HTML document.

Viewport Meta Tag Example

<meta
    name="viewport"
    content="width=device-width"
>

Common Modern Example

<meta
    name="viewport"
    content="width=device-width, initial-scale=1.0"
>

Example Explained

  • name="viewport": Identifies viewport configuration metadata.
  • width=device-width: Sets the viewport width to the device width.
  • initial-scale=1.0: Specifies the initial zoom scale.

Why Is the Viewport Meta Tag Important?

Some mobile browsers historically used a wider virtual viewport to display websites originally designed for desktop computers.

Without the viewport meta tag, a browser might render a desktop-sized layout and shrink it to fit a mobile screen.

This can prevent responsive media queries from behaving as intended.

Setting the viewport width to the device width helps the browser apply the intended mobile layout.

Summary

Responsive web design is a modern approach to developing websites that work effectively across different devices, screen sizes, and resolutions.

It combines flexible layouts, responsive media, adaptable typography, and appropriate viewport settings to improve usability.

Key Concepts Learned

  • Responsive Web Design: Creates flexible websites for different devices.
  • Media Queries: Apply styles when selected conditions are met.
  • Breakpoints: Identify points where a layout should change.
  • Mobile-First Design: Begins with smaller screens and progressively enhances the layout for larger screens.
  • Flexbox: Provides flexible one-dimensional layouts.
  • CSS Grid: Provides flexible two-dimensional layouts.
  • Responsive Media: Prevents images and videos from overflowing their containers and supports suitable resources.
  • Responsive Typography: Makes text sizes adaptable across viewports.
  • Viewport Meta Tag: Helps mobile browsers use the intended viewport width.

Final Reminder

Responsive design is not about creating a separate website for every device. It is about building flexible layouts that respond to available space and user needs.

Modern CSS tools make it easier to create websites that remain readable, accessible, and usable across a wide range of devices.
