Learn JavaScript basics and DOM manipulation to create dynamic, interactive, and responsive websites.

What is JavaScript?

JavaScript is a programming language used to make websites interactive and dynamic. It allows developers to respond to user actions, update content, validate forms, create animations, and build web applications.

JavaScript works together with HTML and CSS to create complete websites. HTML defines the content, CSS controls its appearance, and JavaScript adds behavior.

A High-Level Definition

JavaScript is one of the three fundamental technologies used in front-end web development.

  • HTML: Creates the structure of a web page, including headings, paragraphs, images, buttons, and forms.
  • CSS: Controls colors, fonts, spacing, positioning, and responsive layouts.
  • JavaScript: Adds interactive functionality and allows page content to change.

Example: Interactive Button

The following example changes a button's text when a user clicks it. 

<button id="welcomeButton">
    Click Me
</button>

<script>
const button = document.getElementById("welcomeButton");

button.addEventListener("click", function() {
    button.textContent = "Welcome to JavaScript!";
});
</script>

The HTML creates the button, while JavaScript detects the click and updates the displayed text.

So What Can JavaScript Really Do?

JavaScript provides programming features that allow developers to process information and create interactive experiences.

Variables

Variables store values that can be used throughout a program. 

const websiteName = "CodeVerse";
let totalBooks = 10;

console.log(websiteName);
console.log(totalBooks);

Working with Strings

Strings represent text. JavaScript can combine, compare, and modify strings. 

const firstName = "Alex";
const message = "Welcome, " + firstName;

console.log(message);

Responding to Events

Events are actions that occur in a web page, such as clicking a button, typing in a text field, or submitting a form. 

const button = document.querySelector("#saveButton");

button.addEventListener("click", function() {
    alert("Your changes have been saved!");
});

Application Programming Interfaces (APIs)

APIs provide predefined functionality that developers can use without building every feature from scratch. JavaScript can work with browser APIs and external services.

Browser APIs

  • DOM API: Accesses and changes HTML elements and their properties.
  • Geolocation API: Requests access to the user's geographical location.
  • Canvas API: Draws graphics, shapes, and animations.
  • WebGL API: Supports advanced graphics rendering.
  • Audio and Video APIs: Control multimedia playback and related features.

Third-Party APIs

Third-party APIs are provided by external services. They allow websites to integrate features such as maps, weather information, and social media content.

Examples include mapping services and APIs that retrieve information from other websites.

What Is JavaScript Doing on Your Page?

When a browser opens a web page, it processes HTML, applies CSS, and executes JavaScript. JavaScript can then modify the page while the user interacts with it.

Browser Security

Browsers use security restrictions to help prevent websites from accessing private information or interfering with unrelated websites.

JavaScript generally operates within the security environment provided by the browser. Access to sensitive features may require user permission.

JavaScript Running Order

JavaScript statements generally execute in sequence. Variables and elements must be available before code attempts to use them. 

const username = "Alex";

console.log(username);

const greeting = "Hello, " + username;

console.log(greeting);

In this example, the username is defined before it is used to create the greeting.

Interpreted Versus Compiled Code

Programming languages can use different methods to prepare and execute instructions.

  • Interpreted execution: Processes instructions during program execution.
  • Compiled execution: Transforms source code into another representation before it runs.

Modern JavaScript engines commonly use just-in-time compilation to improve performance. Developers can still write JavaScript directly without manually compiling ordinary browser scripts.

Client-Side Versus Server-Side JavaScript

Client-side JavaScript runs in the user's browser. It is commonly responsible for interactive buttons, form behavior, and dynamic page updates.

Server-side JavaScript runs on a server, often using environments such as Node.js. It can process requests, interact with databases, and generate responses. 

// Client-side example
document.title = "CodeVerse Library";

// Server-side Node.js example
console.log("Server application started");

Both approaches can work together to build complete web applications.

How Do You Add JavaScript to Your Page?

JavaScript is connected to HTML using the <script> element. Scripts can be written directly inside HTML or stored in external files.

Internal JavaScript

Internal JavaScript is written inside a script element in the HTML document. 

<button id="helloButton">
    Say Hello
</button>

<script>
document.getElementById("helloButton")
    .addEventListener("click", function() {
        alert("Hello, CodeVerse!");
    });
</script>

External JavaScript

External JavaScript is stored in a separate file with the .js extension. This makes code easier to organize and maintain.

HTML:

<script src="script.js" defer></script>

script.js:

console.log("External JavaScript loaded!");

Inline JavaScript

JavaScript can also be written directly inside an HTML event attribute. 

<button onclick="alert('Hello!')">
    Click Me
</button>

Although inline JavaScript works, using addEventListener() in a separate script is generally preferred because it keeps HTML and JavaScript responsibilities separate.

Script Loading Strategies

The position and attributes of a script element influence when JavaScript executes.

  • defer: Downloads a classic external script while HTML is being parsed, then executes it after parsing is complete.
  • async: Downloads a script without blocking parsing and executes it when available, without guaranteeing order relative to other scripts.
  • type="module": Loads JavaScript as a module and defers execution by default. 
<script src="app.js" defer></script>

<script src="analytics.js" async></script>

<script type="module" src="main.js"></script>

Comments

Comments are notes written inside source code to explain its purpose. JavaScript ignores comments when executing a program.

Single-Line Comments

A single-line comment begins with two forward slashes. 

// Display a message
console.log("Hello World");

Multi-Line Comments

Multi-line comments begin with /* and end with */. They are useful for explanations spanning several lines. 

/*
    This function displays a welcome
    message in the browser console.
*/

function welcome() {
    console.log("Welcome to CodeVerse!");
}

Why Comments Are Important

  • Explain complicated code.
  • Help developers understand program behavior.
  • Improve teamwork and maintainability.
  • Document important decisions.

Summary

JavaScript adds dynamic functionality to websites. It works alongside HTML and CSS, supports variables, events, and APIs, and can run in both browsers and server environments.

Developers can add JavaScript internally or through external files, control script loading, and use comments to make programs easier to understand.

DOM Scripting Introduction

DOM scripting is the process of using JavaScript to access and modify the structure, content, and appearance of a web page.

The Document Object Model, or DOM, provides a programming interface that represents an HTML document as a collection of connected objects.

The Important Parts of a Web Browser

JavaScript interacts with several browser objects that provide access to different features.

The Window Object

The window object represents the browser window or tab containing the web page. 

console.log(window.innerWidth);
console.log(window.innerHeight);

These properties return the dimensions of the browser's viewport.

The Navigator Object

The navigator object provides information about the browser and selected capabilities. 

console.log(navigator.language);
console.log(navigator.onLine);

The Document Object

The document object represents the web page and allows JavaScript to access its elements. 

console.log(document.title);

document.title = "Learning DOM Scripting";

The Document Object Model

The DOM organizes an HTML document into a tree-like structure. Each element, text section, and other document component is represented by a node.

Example HTML Structure

<html>
    <body>
        <section>
            <h1>CodeVerse</h1>
            <p>Learn JavaScript</p>
        </section>
    </body>
</html>

DOM Tree Representation

HTML
 └── BODY
      └── SECTION
           ├── H1
           │    └── "CodeVerse"
           └── P
                └── "Learn JavaScript"

DOM Node Relationships

  • Root Node: The topmost element of the document tree.
  • Parent Node: A node that contains another node.
  • Child Node: A node directly contained within another node.
  • Sibling Nodes: Nodes that share the same parent.
  • Descendant Node: A node contained anywhere inside another node, even several levels deeper.

Understanding these relationships helps developers navigate and manipulate HTML elements.

Doing Some Basic DOM Manipulation

DOM manipulation allows JavaScript to select elements, change their content, create new elements, remove existing elements, and modify styles.

Selecting an Element

The querySelector() method returns the first element matching a CSS selector. 

const heading = document.querySelector("h1");

console.log(heading);

Selecting Multiple Elements

The querySelectorAll() method returns all matching elements as a NodeList. 

const paragraphs = document.querySelectorAll("p");

paragraphs.forEach(function(paragraph) {
    console.log(paragraph.textContent);
});

Other Selection Methods

// Select by ID
const title = document.getElementById("pageTitle");

// Select by tag name
const items = document.getElementsByTagName("li");

Changing Text Content

The textContent property allows developers to read or replace the text inside an element. 

const title = document.getElementById("pageTitle");

title.textContent = "Welcome to CodeVerse";

Changing Attributes

JavaScript can update attributes such as href, src, alt, and class. 

const link = document.querySelector("#resourceLink");

link.href = "https://developer.mozilla.org/";
link.textContent = "Visit MDN";

Creating New Elements

The createElement() method creates an HTML element that can be inserted into the page. 

const paragraph = document.createElement("p");

paragraph.textContent = "This is a new paragraph.";

document.body.appendChild(paragraph);

Creating Text Nodes

Text nodes can be created separately and attached to existing elements. 

const message = document.createElement("p");

const text = document.createTextNode(
    "JavaScript can create text dynamically."
);

message.appendChild(text);

document.body.appendChild(message);

Removing Elements

The remove() method deletes an element from the DOM. 

const message = document.querySelector("#oldMessage");

if (message) {
    message.remove();
}

Moving Elements

Appending an existing DOM element to a different parent moves that element to its new position. 

const item = document.querySelector("#bookItem");
const container = document.querySelector("#bookContainer");

if (item && container) {
    container.appendChild(item);
}

Manipulating CSS Styles

JavaScript can change inline styles through an element's style property. 

const heading = document.querySelector("#pageTitle");

heading.style.color = "blue";
heading.style.fontSize = "30px";
heading.style.backgroundColor = "lightgray";

Using CSS Classes

The classList property provides methods for adding, removing, and toggling CSS classes. This is often preferable to setting many individual inline styles. 

const container = document.querySelector("#content");

container.classList.add("active");
container.classList.remove("hidden");
container.classList.toggle("dark-mode");

Creating a Dynamic Shopping List

A dynamic shopping list demonstrates how JavaScript can create and remove HTML elements in response to user input.

Learning Objectives

  • Read text from an input field.
  • Create new list items.
  • Display items on the page.
  • Remove items using buttons.
  • Clear and refocus the input field.

Interactive Example

    JavaScript Implementation

    The following script selects the form and list, creates new elements when an item is submitted, and removes items when their Delete buttons are clicked. 

    const form = document.getElementById("cvShoppingForm");
const input = document.getElementById("cvShoppingInput");
const list = document.getElementById("cvShoppingList");

form.addEventListener("submit", function(event) {

    event.preventDefault();

    const itemName = input.value.trim();

    if (itemName === "") {
        return;
    }

    const listItem = document.createElement("li");
    const itemText = document.createElement("span");
    const deleteButton = document.createElement("button");

    itemText.textContent = itemName;
    deleteButton.textContent = "Delete";
    deleteButton.type = "button";

    listItem.appendChild(itemText);
    listItem.appendChild(deleteButton);

    list.appendChild(listItem);

    deleteButton.addEventListener("click", function() {
        listItem.remove();
    });

    input.value = "";
    input.focus();

});

    How the Program Works

    1. The user enters the name of an item.
    2. The form's submit event is detected.
    3. preventDefault() stops the page from reloading.
    4. JavaScript creates a list item and a Delete button.
    5. The new item is appended to the shopping list.
    6. Clicking Delete removes that item.
    7. The input is cleared and focused for the next entry.

    Summary

    DOM scripting allows developers to control web page content using JavaScript. The DOM represents HTML as a tree of connected nodes that can be selected, created, modified, moved, and removed.

    By combining DOM methods with event listeners, developers can build interactive features such as shopping lists, navigation menus, form validation, and dynamic book libraries.

    Lesson 10: JavaScript Syntax and Statements

    JavaScript programs contain statements, expressions, identifiers, and blocks. Statements describe actions; expressions produce values. Use semicolons consistently and braces to group related statements.

    JavaScript Example

    const bookTitle = "CodeVerse";
console.log(bookTitle);

    Key Takeaway

    Use meaningful names and consistent formatting so code is easier to debug.

    Lesson 11: Variables, Constants, and Scope

    Use const for bindings that are not reassigned and let for values that change. Block scope limits access to variables declared inside braces. Avoid var in new code because its function-scoping behavior can be surprising.

    JavaScript Example

    const course = "JavaScript";
let completed = 0;
if (completed === 0) {
  const status = "Starting";
  console.log(status);
}

    Key Takeaway

    Choose const by default and let when reassignment is necessary.

    Lesson 12: JavaScript Data Types

    Primitive values include string, number, boolean, bigint, undefined, symbol, and null. Objects hold collections of properties. typeof helps inspect values, although typeof null returns "object" for historical reasons.

    JavaScript Example

    const title = "DOM";
const pages = 30;
const published = true;
const metadata = { title, pages };
console.log(typeof pages, metadata.title);

    Key Takeaway

    Know the difference between primitives and objects before comparing or modifying values.

    Lesson 13: Operators and Expressions

    Arithmetic operators calculate values; comparison operators test relationships; logical operators combine conditions. Strict equality (===) compares without implicit type conversion and is usually preferable to ==.

    JavaScript Example

    const score = 8;
const passed = score >= 6 && score <= 10;
console.log(`Passed: ${passed}`);

    Key Takeaway

    Use parentheses to make complex expressions easy to read.

    Lesson 14: Strings and Template Literals

    Strings represent text. Template literals use backticks and ${...} placeholders to insert expressions. String methods such as trim(), includes(), and toLowerCase() help process user input.

    JavaScript Example

    const name = "  CodeVerse  ".trim();
const greeting = `Welcome to ${name}!`;
console.log(greeting.toLowerCase());

    Key Takeaway

    Use textContent rather than innerHTML when displaying untrusted text.

    Lesson 15: Conditional Statements

    if, else if, and else run code based on conditions. switch can handle several known values. A ternary expression is useful for a short two-way choice but should not obscure readability.

    JavaScript Example

    const points = 85;
if (points >= 90) {
  console.log("Excellent");
} else if (points >= 75) {
  console.log("Passed");
} else {
  console.log("Keep practicing");
}

    Key Takeaway

    Conditions should be explicit and cover relevant edge cases.

    Lesson 16: Loops and Iteration

    Loops repeat tasks. for is useful when an index is needed, while for...of reads values from iterables such as arrays. while repeats until its condition becomes false. Avoid loops that never terminate.

    JavaScript Example

    const topics = ["HTML", "CSS", "JavaScript"];
for (const topic of topics) {
  console.log(topic);
}

    Key Takeaway

    Use for...of for readable array iteration when you do not need an index.

    Lesson 17: Functions and Parameters

    Functions group reusable logic. Parameters receive inputs and return sends a result back to the caller. Functions can be declared with function or assigned to variables using arrow syntax.

    JavaScript Example

    function calculateTotal(price, quantity) {
  return price * quantity;
}
const double = value => value * 2;
console.log(calculateTotal(50, 3), double(4));

    Key Takeaway

    Prefer small functions with a clear purpose and predictable return value.

    Lesson 18: Arrays and Array Methods

    Arrays store ordered values. push() adds an item, map() transforms each item, filter() selects matching items, and find() retrieves the first match. Array indices begin at zero.

    JavaScript Example

    const books = ["HTML", "CSS", "JavaScript"];
const shortNames = books.filter(book => book.length <= 4);
console.log(shortNames);

    Key Takeaway

    Choose array methods that communicate the intended operation.

    Lesson 19: Objects and Properties

    Objects organize related data using key-value properties. Read properties with dot notation or brackets; methods are functions stored as properties. Optional chaining (?.) safely reads a possibly missing nested property.

    JavaScript Example

    const book = { title: "JavaScript Basics", pages: 120 };
book.pages = 125;
console.log(book.title, book.author?.name);

    Key Takeaway

    Objects are useful for representing a book, user, or application setting.

    Lesson 20: Destructuring and Spread Syntax

    Destructuring extracts properties or array entries into variables. Spread syntax (...) copies enumerable properties or expands iterable values. A spread copy is shallow, so nested objects still share references.

    JavaScript Example

    const book = { title: "DOM Guide", year: 2026 };
const { title } = book;
const updated = { ...book, year: 2027 };
console.log(title, updated);

    Key Takeaway

    Remember that spreading an object does not deeply clone nested data.

    Lesson 21: Errors and Debugging

    Syntax errors prevent parsing, while runtime errors occur during execution. Use the browser console, breakpoints, and try/catch around operations that may fail. Log useful context without exposing sensitive information.

    JavaScript Example

    try {
  const data = JSON.parse("{invalid json}");
  console.log(data);
} catch (error) {
  console.error("Could not parse data:", error.message);
}

    Key Takeaway

    Debug the cause of an error rather than hiding it with an empty catch block.

    Lesson 22: Advanced DOM Selection

    querySelector() returns the first matching element and querySelectorAll() returns a static NodeList. closest() finds a matching ancestor, and matches() checks whether an element satisfies a selector. Check for null before accessing a missing element.

    JavaScript Example

    const card = document.querySelector(".book-card");
if (card) {
  const heading = card.querySelector("h3");
  console.log(heading?.textContent);
}

    Key Takeaway

    Use specific selectors and verify elements exist before modifying them.

    Lesson 23: Traversing the DOM Tree

    DOM elements have parentElement, children, firstElementChild, and nextElementSibling relationships. These properties help navigate a known structure without repeatedly searching the entire document.

    JavaScript Example

    const list = document.querySelector("#cvShoppingList");
if (list) {
  console.log(list.children.length);
  console.log(list.firstElementChild);
}

    Key Takeaway

    Element-based properties skip text nodes, which often simplifies traversal.

    Lesson 24: Event Handling and Event Objects

    addEventListener() registers a callback for events such as click, input, change, and submit. The event object identifies the target and can prevent a default browser action. Use named handlers when you need to remove them later.

    JavaScript Example

    const button = document.querySelector("#saveButton");
if (button) {
  button.addEventListener("click", event => {
    console.log("Clicked:", event.currentTarget.id);
  });
}

    Key Takeaway

    Prefer addEventListener() over inline HTML event attributes.

    Lesson 25: Event Delegation and Bubbling

    Many events bubble from the target element to ancestors. Event delegation attaches one listener to a parent and checks which child initiated the event. This is helpful for dynamically added list items.

    JavaScript Example

    const list = document.querySelector("#cvShoppingList");
list?.addEventListener("click", event => {
  const button = event.target.closest("button");
  if (button && list.contains(button)) {
    button.closest("li")?.remove();
  }
});

    Key Takeaway

    Delegation can reduce the number of listeners in a dynamic interface.

    Lesson 26: Working with Forms and Inputs

    JavaScript reads form values through input.value, checks form validity, and can respond to submit events. The FormData API collects successful form controls that have name attributes. Client-side validation improves usability but must be repeated on the server.

    JavaScript Example

    const form = document.querySelector("#profileForm");
form?.addEventListener("submit", event => {
  event.preventDefault();
  if (!form.reportValidity()) return;
  const values = new FormData(form);
  console.log(values.get("username"));
});

    Key Takeaway

    Never treat browser-side validation as a security boundary.

    Lesson 27: Timers and the Event Loop

    setTimeout() schedules a callback after a delay; setInterval() repeats a callback. JavaScript uses an event loop to coordinate tasks, so timers do not guarantee execution at an exact millisecond. Clear timers when they are no longer needed.

    JavaScript Example

    const timerId = setTimeout(() => {
  console.log("Reminder shown");
}, 1000);
// clearTimeout(timerId) cancels it.

    Key Takeaway

    Timers schedule future work; they do not pause the entire browser.

    Lesson 28: Promises and Async/Await

    Promises represent future success or failure of asynchronous work. async functions return promises, and await lets code handle their outcomes in a readable order. Catch rejections so failures do not go unnoticed.

    JavaScript Example

    async function loadMessage() {
  try {
    const result = await Promise.resolve("Ready");
    console.log(result);
  } catch (error) {
    console.error(error);
  }
}
loadMessage();

    Key Takeaway

    Use try/catch with awaited operations that may reject.

    Lesson 29: Fetching Data from APIs

    fetch() makes HTTP requests and returns a Response object. Check response.ok because HTTP error statuses do not automatically reject the promise. Parse JSON only when the response format is JSON.

    JavaScript Example

    async function loadBooks() {
  const response = await fetch("/api/books");
  if (!response.ok) throw new Error(`HTTP ${response.status}`);
  return response.json();
}

    Key Takeaway

    Handle network failures and unexpected response formats gracefully.

    Lesson 30: Browser Storage and Safe DOM Updates

    localStorage stores string data across browser sessions and sessionStorage lasts for a tab session. Avoid storing secrets or authentication tokens in web storage. Use textContent to render user-provided strings and validate URLs before assigning them to links.

    JavaScript Example

    localStorage.setItem("readerFontSize", "18px");
const size = localStorage.getItem("readerFontSize");
const output = document.querySelector("#status");
if (output) output.textContent = `Font size: ${size}`;

    Key Takeaway

    Store only non-sensitive preferences and never insert untrusted strings as HTML.
