HTML Introduction

HTML is the foundation of web development. It provides the structure used to organize text, images, links, and other content on websites.

What is HTML?

HTML stands for HyperText Markup Language. It is the standard language used to structure content displayed in web browsers.

  • HTML defines the structure of web pages.
  • HTML uses elements to organize content.
  • HTML elements are represented by tags.
  • Browsers interpret HTML to display web pages.
  • HTML identifies headings, paragraphs, links, and images.

A Simple HTML Document

An HTML document contains elements that define the page's structure and visible content.

Example

<!DOCTYPE html>
            <html lang="en">
            <head>
                <meta charset="UTF-8">
                <title>My First Website</title>
            </head>
            <body>
                <h1>Welcome to My Website</h1>
                <p>Learning HTML is fun!</p>
            </body>
            </html>

Example Explained

  • <!DOCTYPE html> declares the HTML document type.
  • <html> is the root element of the document.
  • <head> contains metadata and document settings.
  • <title> sets the title displayed in the browser tab.
  • <body> contains the visible page content.
  • <h1> defines a primary heading.
  • <p> defines a paragraph.

What is an HTML Element?

An HTML element usually consists of an opening tag, content, and a closing tag. 

<h1>Hello World</h1>

            <p>This is a paragraph.</p>

Parts of an HTML Element

Opening Tag Content Closing Tag
<h1> Hello World </h1>
<p> This is a paragraph. </p>
<br> No content Not required

Note: Some elements, such as <br> and <img>, are void elements. They do not require closing tags.

Web Browsers

A web browser is an application that reads HTML documents and displays them as web pages.

Popular web browsers include:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari
  • Opera

Browsers interpret HTML elements and render the content without displaying the HTML tags themselves.

Browser Output Example

Welcome to My Website

Learning HTML is fun!

HTML Page Structure

Every HTML document follows a basic structure. The head contains document information, while the body contains the content users can see. 

<html>

        <head>
            <title>Page Title</title>
        </head>

        <body>

            <h1>Main Heading</h1>

            <p>First paragraph.</p>

            <p>Second paragraph.</p>

        </body>

    </html>

Remember: Content inside the <body> is rendered on the page, while the <title> identifies the document in the browser tab.

HTML History

HTML has developed through several versions since the creation of the World Wide Web. Each major update introduced improvements to web document structure and capabilities.

Year Development
1989 Tim Berners-Lee proposed the World Wide Web.
1991 HTML was introduced for creating web documents.
1993 Dave Raggett proposed HTML+.
1995 HTML 2.0 became a formal specification.
1997 HTML 3.2 became a W3C Recommendation.
1999 HTML 4.01 was published.
2000 XHTML 1.0 was released.
2008 The first public HTML5 draft was published by WHATWG.
2012 WHATWG adopted the HTML Living Standard.
2014 HTML5 became a W3C Recommendation.
2016 HTML 5.1 reached Candidate Recommendation status.
2017 HTML 5.1 Second Edition and HTML 5.2 were published.

Modern HTML continues to evolve through the HTML Living Standard, which supports the development of today's websites and web applications.

HTML Semantic Elements

Semantic elements are HTML elements that clearly describe the purpose and meaning of their content. They help developers and web browsers understand how different parts of a webpage are organized.

HTML provides semantic elements that make web pages more meaningful, readable, and easier to maintain.

What are Semantic Elements?

A semantic element is an HTML element whose name communicates the type or purpose of the content it contains.

Semantic elements describe their meaning to both the web browser and the developer.

Non-Semantic Elements

Non-semantic elements do not explain what their content represents. They are commonly used as general-purpose containers.

  • <div> - A general container used to group HTML elements.
  • <span> - An inline container used to group text or other inline content.

Example of Non-Semantic HTML

<div class="header">
        <h1>My Website</h1>
    </div>

    <div class="content">
        <p>Welcome to my website.</p>
    </div>

Although these elements can organize content, their tag names do not identify the purpose of each section.

Semantic Elements

Semantic elements provide meaningful information about the content they contain.

  • <img> - Represents an image.
  • <table> - Represents tabular data.
  • <article> - Represents independent, self-contained content.

Example of Semantic HTML

<header>
        <h1>My Website</h1>
    </header>

    <main>
        <article>
            <h2>Welcome</h2>
            <p>This is my first article.</p>
        </article>
    </main>

In this example, the elements identify the page header, main content, and an independent article.

Semantic Elements in HTML

Many websites previously relied on generic containers with IDs or classes to identify different parts of a webpage.

Example of Traditional HTML Structure

<div id="header">
        Website Header
    </div>

    <div id="nav">
        Navigation Menu
    </div>

    <div id="content">
        Main Content
    </div>

    <div id="footer">
        Website Footer
    </div>

Modern HTML provides semantic elements that describe the different areas of a webpage more clearly.

Common HTML Semantic Elements

  • <article>
  • <aside>
  • <details>
  • <figcaption>
  • <figure>
  • <footer>
  • <header>
  • <main>
  • <mark>
  • <nav>
  • <section>
  • <summary>
  • <time>

Example of Semantic Page Structure

<header>
        <h1>CodeVerse Library</h1>
    </header>

    <nav>
        <a href="index.html">Home</a>
        <a href="library.html">Library</a>
    </nav>

    <main>

        <section>
            <h2>Featured Books</h2>

            <article>
                <h3>HTML Fundamentals</h3>
                <p>Learn the basics of HTML.</p>
            </article>

        </section>

        <aside>
            <h3>Related Topics</h3>
            <p>CSS and JavaScript</p>
        </aside>

    </main>

    <footer>
        <p>CodeVerse Digital Library</p>
    </footer>

Using semantic elements helps describe the structure of a webpage without depending entirely on generic containers.

HTML Attributes

Attributes provide additional information about an element and appear in its opening tag. They control behavior, identify elements, and connect resources.

Example

<a href="/library.html" title="Browse books">Browse books</a>

Key Takeaway

Use descriptive attributes and quote attribute values for readability.

Global HTML Attributes

Global attributes such as id, class, lang, title, hidden, and data-* can be used on most HTML elements. An id should be unique within a document; classes may be shared.

Example

<section id="featured" class="book-section" data-year="first">Featured books</section>

Key Takeaway

Use class for reusable styling and id for unique targets.

Headings and Paragraphs

Headings h1 through h6 establish the hierarchy of topics, while paragraphs organize readable blocks of text. Choose heading levels by structure rather than visual size.

Example

<h1>Web Development</h1>
<h2>HTML Basics</h2>
<p>HTML structures webpage content.</p>

Key Takeaway

Use one clear primary heading and logical subheadings.

Text-Level Semantic Elements

Elements such as strong, em, abbr, code, and mark communicate meaning within text. Strong indicates importance and em indicates stress emphasis, unlike purely decorative styling.

Example

<p><strong>Important:</strong> Save your work. <abbr title="HyperText Markup Language">HTML</abbr> uses tags.</p>

Key Takeaway

Prefer semantic emphasis over appearance-only tags.

Hyperlinks and Navigation

The anchor element creates links to pages, downloads, email addresses, and locations within a document. The href attribute defines the destination; link text should describe its purpose.

Example

<nav aria-label="Primary"><a href="/index.html">Home</a> <a href="#contact">Contact section</a></nav>

Key Takeaway

Avoid vague link text such as “click here.”

Images and Alternative Text

The img element embeds an image. Its alt attribute provides a text alternative for meaningful images; decorative images may use an empty alt value. Width and height can help reserve layout space.

Example

<img src="/images/CodeVerseLogo.png" alt="CodeVerse logo" width="80" height="80">

Key Takeaway

Describe the image’s meaning rather than repeating “image of.”

Ordered, Unordered, and Description Lists

Use ul for unordered items, ol for sequential steps, and dl with dt and dd for terms and definitions. Each list communicates a different relationship among its contents.

Example

<ol><li>Open the editor</li><li>Create index.html</li><li>Save the file</li></ol>

Key Takeaway

Choose list markup based on meaning, not the desired bullet appearance.

Semantic Data Tables

Tables represent data arranged in rows and columns. Use caption, th, and scope to identify the table and its headers. Avoid tables for page layout.

Example

<table><caption>Study Schedule</caption><tr><th scope="col">Day</th><th scope="col">Topic</th></tr><tr><td>Monday</td><td>HTML</td></tr></table>

Key Takeaway

Keep headers associated with their data cells.

HTML Forms and Labels

A form collects user input. Label elements associate descriptive text with controls, and the name attribute identifies values submitted to a server.

Example

<form action="/contact" method="post"><label for="email">Email</label><input id="email" name="email" type="email" required><button type="submit">Send</button></form>

Key Takeaway

Pair each input with a visible label.

The Header Element

The header element represents introductory content for a page or section. It may contain a title, logo, or related introductory information, and can appear in multiple sections.

Example

<article><header><h2>Internet Basics</h2><p>Lesson overview</p></header><p>Lesson content...</p></article>

Key Takeaway

Do not assume every header is the global site header.

The Navigation Element

The nav element identifies a major block of navigation links, such as primary menus or a table of contents. Not every group of links requires a nav element.

Example

<nav aria-label="Book chapters"><a href="#chapter-one">Chapter One</a></nav>

Key Takeaway

Give multiple navigation regions distinct accessible labels.

The Main Element

The main element contains the dominant content of the document. A page should generally have one visible main landmark, separate from repeated navigation and site-wide content.

Example

<header>CodeVerse</header><main><h1>HTML Guide</h1><p>Start here.</p></main>

Key Takeaway

Keep repeated site headers and footers outside main.

Section vs. Article

A section groups related content by theme, usually with a heading. An article is a self-contained composition that can stand independently, such as a news item or book review.

Example

<section><h2>Recent Posts</h2><article><h3>Learning HTML</h3><p>A short post.</p></article></section>

Key Takeaway

Ask whether the content could make sense on its own before choosing article.

Aside and Footer Elements

An aside holds tangentially related information, such as a sidebar or related resources. A footer contains closing information about its nearest sectioning ancestor or the page.

Example

<article><h2>HTML</h2><p>Main explanation.</p><aside><h3>Related</h3><p>Read about CSS.</p></aside><footer>Updated 2026</footer></article>

Key Takeaway

Use aside only for supporting rather than primary content.

Figure and Figcaption

The figure element groups self-contained illustrative content, including diagrams, images, or code listings. Figcaption supplies a caption associated with the figure.

Example

<figure><img src="/images/CodeVerseLogo.png" alt="CodeVerse emblem"><figcaption>Figure 1. CodeVerse branding.</figcaption></figure>

Key Takeaway

Use figure when the content benefits from a meaningful caption.

Details and Summary

The details element creates a disclosure widget that users can expand or collapse. The summary element provides its visible label, supporting accessible interactive explanations without custom JavaScript.

Example

<details><summary>What is semantic HTML?</summary><p>Markup that communicates content meaning.</p></details>

Key Takeaway

Write a summary that clearly explains what will be revealed.

Time and Address Elements

The time element represents dates or times in a machine-readable way using datetime. The address element provides contact information for the nearest article or document.

Example

<p>Published <time datetime="2026-11-16">November 16, 2026</time>.</p>

Key Takeaway

Use machine-readable dates when publishing schedules or updates.

Accessible HTML Structure

Semantic landmarks, logical headings, descriptive links, labels, and alternative text help users navigate content with assistive technology. Native HTML controls often provide built-in keyboard interaction.

Example

<main id="content"><h1>Library</h1><a href="/books.html">Browse available books</a></main>

Key Takeaway

Test the page using keyboard-only navigation and a screen reader when possible.

Document Metadata and SEO Basics

Metadata in head describes the document to browsers and search engines. The title element identifies the page, while a meta description can summarize its purpose. Metadata does not replace useful content.

Example

<title>HTML Guide | CodeVerse</title>
<meta name="description" content="Learn HTML structure and semantic elements.">

Key Takeaway

Write a unique, informative title for each page.

HTML Validation and Best Practices

HTML validation helps detect incorrect nesting, missing attributes, and structural errors. Review markup with the Nu HTML Checker and test rendering, responsiveness, and keyboard accessibility.

Example

<!DOCTYPE html>
<html lang="en">
<head><meta charset="utf-8"><title>Valid Page</title></head>
<body><main><h1>Hello</h1></main></body>
</html>

Key Takeaway

Validate regularly and fix errors rather than relying on browser recovery.
