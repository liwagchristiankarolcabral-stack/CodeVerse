Introduction: The Internet

What is the Internet?

  • The Internet is a global Wide Area Network (WAN).
  • A Network is a group of interconnected devices.
  • A Wide Area Network (WAN) is a network that covers a large area.
  • A Local Area Network (LAN) is a network that covers a small area.

What are the main advantages of the Internet?

  • Communication: Electronic mail (Email) and social media.
  • Education: search engines and webpages.
  • Entertainment: online games and online media.
  • Online services: online shopping and online banking.

What are the main disadvantages of the Internet?

  • Threat to personal information: possible loss of name, address, credit card number,...
  • Spamming: unwanted Emails that serve no purpose.
  • Cybercrime: malware, ransomware, stealing of identities,...
  • Virus attacks: cause a system to crash and may delete important data.

History of the Internet

  • In the 1950s, the United States Defense Department formed the Advanced Research Projects Agency (ARPA) with the purpose of developing technology.
  • ARPA’s scientists could not easily communicate or share information, so they created a network of computers, which they called ARPAnet.
  • In the 1970s, the TCP/IP protocol was developed, this protocol allowed the separate networks to communicate with each other.
  • The joining of these networks created a huge WAN which came to be known as the Internet.

The World Wide Web (WWW)

What is the World Wide Web (WWW)?

  • The World Wide Web (WWW) is a collection of different websites that can be accessed through a web browser.
  • A website is a group of webpages hosted on one web server.
  • A web server is an Internet server that serves webpages to the web browser.
  • A web browser is an application that displays webpages.

What is the difference between the World Wide Web (WWW) and the Internet?

  • The Internet is a global WAN, and the WWW is an Internet service.

How the World Wide Web (WWW) works?

  • When a user makes a request over the Internet, the web browser sends this request to a web server, and the web server accepts and responds to it by storing and transferring webpages to the web browser.

How are web pages transferred from servers to clients?

  • Any resource connected to the WWW is identified by its Uniform Resource Locator (URL).
  • A Uniform Resource Locator (URL) is the address of a WWW page.
  • Example: http://www.example.com/...
  • When the URL of a web page is identified, a protocol called Hyper Text Transfer Protocol (HTTP) sends a command to the web server.
  • Hyper Text Transfer Protocol (HTTP) is a protocol which enables communication between web clients and web servers.
  • Once the web server has transmitted the requested page, the web page can be displayed with Hyper Text Markup Language (HTML).
  • Hypertext Markup Language (HTML) is the standard language for creating and displaying web pages.

History of the World Wide Web (WWW)

  • In 1990, the WWW was invented by Tim Berners-Lee.
  • He created three technologies (HTML, URL and HTTP), which allowed to use the Internet to link one document directly to another.

Internet Connectivity

What is needed to connect to the Internet?

  • Internet Service Provider (ISP): a business that provides a connection to the Internet.
  • Modem: a piece of hardware that allows a device to connect to the Internet over a telephone line.
  • Router: a piece of hardware that allows several devices to connect to a single Internet connection.

Common methods of Internet connection

  • Dial-up: an Internet connection which uses a telephone line and requires a landline.
  • Digital Subscriber Line (DSL): an Internet connection which uses a telephone line, but doesn’t require a landline.
  • Cable TV: a wired Internet connection which uses Cable TV lines.
  • Wi-Fi: a wireless Internet connection which uses radio waves.
  • Satellite: a wireless Internet connection which uses satellites orbiting the Earth.
  • 3G, 4G, and 5G: wireless Internet connections which uses cellular networks.

Cloud Computing

What is cloud computing?

  • Cloud computing is the process of storing and using services online, rather than storing them locally on a device.

What are the main advantages of cloud computing?

  • File storage: access files, documents and Emails from any device.
  • File sharing: share files with several people at the same time.
  • Backing up: protect your files.

What are the main disadvantages of cloud computing?

  • Copyright: possible loss of legal rights.
  • Security: vulnerability to security attacks.
  • Storage: expense of storage.

Web Browsers

What is a Web browser?

  • A Web browser is an application that displays Webpages.

Main functions of a Web browser

  • Retrieval: the process of bringing information to the user.
  • Display: the process of showing information to the user.
  • Navigation: the process of moving around a Website in order to access other information.

Graphical User Interface (GUI) elements of a Web browser

  • Navigation buttons: back, forward, refresh, stop, and home buttons.
    • The back button retrieves the previous Web page that referred to the Web page currently viewed.
    • The forward button retrieves to the forward Web page and only works if the back button has been previously used.
    • The refresh button reloads the Web page that is currently viewed.
    • The stop button stops a Web page from loading.
    • The home button retrieves the default Web page.
  • Address bar: a text field used to input the URL of a Website and display this Website.
  • Search bar: a text field used to input terms and display several Websites.
  • Status bar: a bar that displays information on the URLs of links and information on the Webpage as it loads.

Main features of a Web browser

  • Tabbed browsing: a form of navigation that allows to have multiple Webpages open at the same time.
  • Bookmarks: saved shortcuts that direct to specific Webpages.
  • Browsing history: the list of Webpages a user has visited recently.
  • Page zooming: the ability to reduce or enlarge the content of a Webpage.
  • Downloading: the process of copying data from one device to another.

Main browser extensions

  • Plug-in: an application that adds a specific feature to a program.
    • Adobe Flash Player: an application that allows the user to display multimedia on Web browsers.
    • Adobe Acrobat Reader: an application that allows the user to display Portable Document Format (PDF) files on a Web browser.
    • Microsoft Silverlight: an application that allows a user to use video sites on a Web browser.
  • Pop-up blocker: a program that prevents pop-up windows from appearing on a Website.
    • A pop-up is an online advertising that uses a new window for display.
  • Browser cache: a temporary storage of Web data.
    • The main purpose of a browser cache is to speed up Internet surfing by saving Web data, so that when the user tries to go back to recently visited Web pages, the browser displays them instead of downloading them again.
  • Cookies: small pieces of data exchanged between the Web browser and the Web server that store information about the user.
    • The main purpose of a cookie is to identify the user, prepare custom Web pages and save site login information in order to provide recommendations for the user.

Hyperlinks

What is a hyperlink?

  • A hyperlink is an element that links either to another place in the same document, or to another document.

Structure of a hyperlink

Colors of hyperlinks

  • Blue: unvisited link.
  • Purple: visited link.
  • Red: active link.

Types of hyperlinks

  • Internal: links to a different page in the same Website.
  • External: links to another Website.
  • Relative: links to a specific place in the same page.

Uniform Resource Locators (URLs)

What is a Uniform Resource Locator (URL)?

  • A Uniform Resource Locator (URL) is a unique identifier used to locate a resource on the Internet.

Structure of a Uniform Resource Locator (URL)

Protocol

  • The protocol of a URL determines how data is transferred between the host and a client.

Hostname

  • The hostname identifies the host that holds the resource.
  • The subdomain identifies the location of the resource on the Web server.
  • The domain name identifies the name of the Website.
  • The Top-Level-Domain (TLD) identifies the Website geographical area, or the organization that owns it.

Path

  • The path identifies the specific resource in the host that the client wants to access.

Query string

  • The query string assigns values to specified parameters that the resource can use.

Anchor

  • The anchor identifies the specific location of the resource within a page of the Website.

Culture

The internet has cultivated a unique culture, one with its own norms and etiquette. While specific services and websites often have their own distinct culture, there are a few general rules of thumb that apply most places. These fundamentals are often called netiquette.

Common, but not universal, cultural norms online can include:

Spam

Activities which could be seen as "Spam" should be avoided. These can include unwarranted solicitation of commercial goods, but can also include non-commercial activities, such as sending a large number of messages in quick succession, making nonconstructive posts, or otherwise acting in a way that is seen as detrimental to the community.

Reviving old threads

Most forms typically look down on or prohibit "reviving" or "necroing" old threads by creating new posts in them.

What counts as an old post depends highly on the specific community, with some considering day old threads to be old news, and others allowing for the posting in threads that are several years old.

Generally, it's OK to post in a thread that has had active commentary recently. If a community has a thread that was started in 2008 and has had active discussion to the present day, it's not reviving that thread, since the thread never "died". However posting in a different thread that was started in 2008 and hasn't seen a post since 2009 would likely be seen as reviving a thread, and a potential breach of netiquette.

Types of Computer Networks

Networks connect devices so they can exchange data and share resources. They differ in coverage, ownership, and purpose.

PAN, LAN, MAN, and WAN

A personal area network (PAN) links nearby personal devices; a local area network (LAN) covers a home, office, or campus building; a metropolitan area network (MAN) spans a city; and a wide area network (WAN) covers larger regions.

Intranets and extranets

An intranet is a private network for an organization. An extranet provides controlled access to selected external users, such as partners.

Practical example

A classroom Wi-Fi network is a LAN. When a student uses it to visit an overseas website, traffic passes through interconnected networks across the Internet.

Network Topologies

A network topology describes how network devices are arranged and interconnected.

Star topology

Devices connect to a central switch or access point. It is common in modern local networks.

Bus and ring topologies

A bus uses a shared communication medium, while a ring connects devices in a loop. Both help illustrate network design trade-offs.

Mesh topology

Devices have multiple paths between them, improving redundancy but increasing complexity and cost.

Essential Network Hardware

Networking equipment directs traffic and provides connections between computers and networks.

Switch

Connects devices within a LAN and forwards Ethernet frames toward the correct destination.

Router

Connects different IP networks and chooses where packets should go.

Wireless access point

Allows Wi-Fi devices to join a local network.

Modem and ONT

A modem adapts signals for certain access technologies; an optical network terminal (ONT) terminates a fiber connection.

Data Packets and Packet Switching

Internet data is divided into manageable units so multiple users and applications can share network links.

Packets

An IP packet carries addressing information and a portion of data. Large messages may require many packets.

Packet switching

Routers forward packets across available network paths instead of reserving a dedicated circuit for every conversation.

Delivery and reassembly

Higher-layer protocols and applications help detect missing data, maintain order when needed, and reconstruct the information.

The TCP/IP Model

The TCP/IP suite provides the foundation for communication across interconnected networks.

Application layer

Protocols such as HTTP, DNS, and SMTP support web browsing, name lookup, and email.

Transport layer

TCP provides a reliable ordered byte stream; UDP sends datagrams with less protocol overhead and no built-in delivery guarantee.

Internet and link layers

IP handles addressing and routing, while Ethernet and Wi-Fi transmit data over local connections.

IP Addresses and Subnets

An Internet Protocol (IP) address identifies a network interface for communication within an IP network.

IPv4

IPv4 addresses are 32 bits and are commonly written as four decimal numbers, such as 192.168.1.10.

IPv6

IPv6 addresses are 128 bits and are commonly written in hexadecimal groups, such as 2001:db8::1.

Subnets

A subnet groups addresses under a network prefix. Routers use prefixes to determine how traffic should be forwarded.

Domain Name System (DNS)

DNS translates human-friendly domain names into records that applications can use to find services.

Name resolution

When a user enters a domain, the device can query a DNS resolver for records such as A (IPv4) or AAAA (IPv6).

Caching

Resolvers and devices temporarily store DNS answers to reduce repeated lookups.

Why it matters

DNS lets website operators change server addresses without requiring visitors to memorize IP addresses.

Domain Names and Registration

Domain names provide recognizable identifiers for websites and other Internet services.

Domain structure

In www.example.com, com is a top-level domain, example is a second-level domain, and www is a subdomain.

Registration

Domain names are registered through accredited registrars under applicable registry rules.

Domains versus hosting

Registering a domain does not automatically provide website storage or a running web server; hosting is a separate service.

HTTP and HTTPS

Hypertext Transfer Protocol (HTTP) defines how clients and servers exchange requests and responses.

Requests and responses

A browser sends a request, such as GET /index.html. The server returns a status code, headers, and often a response body.

HTTPS

HTTPS protects HTTP communication using Transport Layer Security (TLS), helping provide encryption and server authentication.

Status codes

200 means success, 301 or 302 indicates redirection, 404 means the resource was not found, and 500 indicates a server-side error.

Client–Server Architecture

Many Internet services use clients that request resources from servers.

Client

A web browser, mobile application, or other program sends requests on behalf of a user.

Server

A server application processes requests and returns web pages, data, files, or other results.

Example

When CodeVerse loads a lesson, the browser requests the page and related files from the hosting service.

Web Hosting and Web Servers

A website must be stored and served through infrastructure that visitors can reach.

Static hosting

Static hosting delivers existing HTML, CSS, JavaScript, and media files.

Dynamic hosting

Dynamic sites use application code and often a database to generate responses or handle accounts.

Deployment basics

A deployment publishes a tested version of a website. Operators also configure domains, HTTPS, monitoring, and backups.

HTML, CSS, and JavaScript

These three core web technologies work together to create interactive web pages.

HTML

HyperText Markup Language structures headings, paragraphs, images, links, forms, and other page content.

CSS

Cascading Style Sheets control colors, typography, spacing, layouts, and responsive presentation.

JavaScript

JavaScript can respond to user actions, update page content, validate inputs, and communicate with servers.

Search Engines and Information Retrieval

Search engines help users discover publicly accessible information on the web.

Crawling

Automated programs discover pages by following links and other discovery signals.

Indexing

A search service processes eligible pages into a searchable index.

Ranking and evaluation

Results are ordered using multiple signals. Students should evaluate source credibility, dates, authorship, and evidence rather than relying on the first result.

Email and Internet Messaging

Email is an Internet service for exchanging messages and attachments.

Addresses

An email address typically uses a local part and domain, such as student@example.com.

SMTP, IMAP, and POP3

SMTP is commonly used to send or relay messages. IMAP synchronizes mailboxes; POP3 retrieves messages.

Safe email habits

Check unexpected senders, avoid suspicious attachments, and verify requests for passwords or money through another channel.

File Transfer and Downloads

Internet users frequently upload and download files between devices and services.

Upload and download

Uploading sends data from a device to a remote service; downloading receives data from a remote service.

Transfer methods

HTTPS commonly transfers files through websites and APIs. SFTP transfers files over a secure SSH connection.

File safety

Confirm file sources, inspect extensions, and use appropriate malware protection before opening unfamiliar downloads.

Wi-Fi and Mobile Data

Wireless Internet access relies on different radio technologies and infrastructure.

Wi-Fi

Wi-Fi typically connects a device to a nearby access point that provides access to a local network.

Mobile networks

4G and 5G connect phones and other devices through cellular base stations and carrier networks.

Performance factors

Signal strength, interference, distance, congestion, and plan limitations can affect speed and reliability.

Bandwidth, Speed, and Latency

Network performance depends on more than the advertised download speed.

Bandwidth and throughput

Bandwidth describes potential carrying capacity; throughput is the rate of data successfully transferred.

Latency

Latency is the time it takes for data to travel between endpoints, often measured in milliseconds.

Packet loss and jitter

Packet loss means data does not arrive. Jitter is variation in delay and can disrupt calls and real-time games.

Internet Security Fundamentals

Cybersecurity protects devices, accounts, networks, and information from unauthorized access and disruption.

Common threats

Phishing, malicious software, stolen credentials, and insecure software can compromise users.

Protection

Use unique passwords, a password manager, multifactor authentication, software updates, and reliable backups.

Secure connections

HTTPS helps protect data in transit, but it does not guarantee that a website or its content is trustworthy.

Online Privacy and Digital Footprints

Internet activity can generate information about users and their behavior.

Personal data

Names, contact details, location data, and account identifiers can be sensitive when linked to a person.

Digital footprints

Posts, searches, account activity, and website interactions may leave records across services.

Privacy practices

Review app permissions, minimize unnecessary sharing, understand privacy settings, and be careful with public posts.

Digital Citizenship and Netiquette

Responsible Internet use involves respectful communication, critical thinking, and ethical behavior.

Netiquette

Communicate respectfully, avoid harassment, and consider how written messages may be interpreted.

Academic integrity

Credit sources, distinguish quotation from paraphrase, and follow rules for using online materials.

Misinformation

Check claims against credible independent sources and verify context before reposting information.

Basic Internet Troubleshooting

A structured troubleshooting process can identify common connection problems.

Check the scope

Determine whether the issue affects one website, one device, or the entire local network.

Inspect connections

Check Wi-Fi or Ethernet status, airplane mode, router power, and whether other devices work.

Test carefully

Try a known website, restart the affected device or router when appropriate, and check for provider outages.

Escalate

If the problem persists, document error messages and contact the network administrator or Internet service provider.

Emerging Internet Technologies

Internet technologies continue to evolve as devices, applications, and network demands change.

Internet of Things (IoT)

Connected sensors and devices exchange information for homes, healthcare, transport, and industry.

Edge computing

Some processing occurs closer to users or devices to reduce delays and unnecessary data transfers.

Newer network technologies

IPv6 adoption, fiber networks, improved wireless systems, and modern web protocols support evolving Internet services.

Responsible adoption

New capabilities should be evaluated for security, accessibility, privacy, and environmental impact.
