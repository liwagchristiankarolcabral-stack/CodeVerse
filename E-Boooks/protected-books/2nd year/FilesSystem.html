File Systems and Storage Management

Learn how computers organize, store, retrieve, manage, and protect digital information using file systems and storage technologies.

CHAPTER 01

Introduction to File Systems

What Is a File System?

A file system is a method used by an operating system to organize, store, name, manage, and retrieve digital files on a storage device.

Whenever a user saves a file, the operating system communicates with the file system to determine where the information should be stored.

How File Systems Work

  1. A user creates or saves a file.
  2. The operating system receives the request.
  3. The file system identifies available storage.
  4. The location of the data is recorded.
  5. The file can be retrieved later.

Importance

  • Organizes files and directories.
  • Allows convenient access to information.
  • Tracks occupied and available storage.
  • Supports file security and permissions.
  • Improves storage efficiency.
CHAPTER 02

Basic Components of a File System

Files

A file is a collection of related information stored under a specific name.

Directories

A directory, commonly called a folder, is used to organize and group files.

Metadata

Metadata describes a file and helps the operating system manage it.

  • File name
  • File size
  • File type
  • Creation date
  • Modification date
  • File permissions

Volumes

A volume is a logical storage area containing a file system. A physical drive may contain one or more volumes.

File System Structure

File systems use directory information, metadata, allocation records, and data blocks to manage stored information.

CHAPTER 03

File Operations

File operations are actions performed on digital files by users and applications.

  • Create: Make a new file.
  • Open: Access a file.
  • Read: Retrieve stored information.
  • Write: Add or modify information.
  • Rename: Change the file name.
  • Copy: Create another version.
  • Move: Transfer a file to another location.
  • Delete: Remove a file.
  • Save: Store updated information.

Deleting a file does not always immediately erase its data from the physical storage device.

CHAPTER 04

File Naming and Extensions

File naming is the process of assigning a meaningful name to a digital file.

A file extension is the group of characters after the final period in a file name.

.pdf PDF document
.jpg Image
.png Image
.mp3 Audio
.mp4 Video
.pptx Presentation
.xlsx Spreadsheet
.txt Plain text
.html Webpage
.java Java source code
.zip Compressed archive

Changing a file extension does not automatically convert the file's actual format.

CHAPTER 05

Directory and Folder Structures

A directory structure describes how files and folders are arranged in a storage system.

Types of Directory Structures

  • Single-level directory
  • Two-level directory
  • Tree-structured directory
  • Acyclic-graph directory
  • General graph directory

Absolute and Relative Paths

An absolute path specifies a complete location, while a relative path identifies a location based on the current working directory.

CHAPTER 06

Types of File Systems

FAT32

An older file system with broad compatibility. It cannot store individual files of 4 GiB or larger.

NTFS

A Microsoft file system commonly used in Windows, supporting permissions, journaling, compression, and encryption features.

exFAT

Designed for portable storage and large files. Commonly used with USB drives and memory cards.

ext4

A widely used Linux file system supporting journaling and efficient block allocation.

APFS

Apple's modern file system, supporting encryption, snapshots, and space sharing.

File System Common Use
FAT32 Compatible removable drives
NTFS Windows computers
exFAT Portable flash storage
ext4 Linux systems
APFS Apple devices
CHAPTER 07

File Allocation Methods

File allocation determines how storage blocks are assigned to files.

Contiguous Allocation

Stores file data in consecutive blocks. It provides fast sequential access but can cause external fragmentation.

Linked Allocation

Stores file data in separate blocks connected through pointers. It allows flexible storage but can make random access slower.

Indexed Allocation

Uses an index block containing the addresses of a file's data blocks. It supports direct access but requires additional index storage.

CHAPTER 08

Disk Storage Organization

Sectors

Sectors are basic physical storage units on many disk devices.

Blocks

Blocks are units used by file systems to allocate and manage data.

Clusters

A cluster is a group of sectors treated as one allocation unit by certain file systems.

File Allocation Table

FAT file systems use a table to track the clusters belonging to files.

Master File Table

NTFS uses the Master File Table to store records describing files and directories.

CHAPTER 09

Introduction to Storage Management

Storage management involves organizing, controlling, maintaining, and protecting digital information on storage devices.

Main Functions

  • Storage allocation
  • Storage monitoring
  • Data organization
  • Data protection
  • Storage optimization
  • Data recovery

For example, a school administrator may monitor available storage, remove unnecessary files, and back up important student records.

CHAPTER 10

Types of Storage Devices

Hard Disk Drive

An HDD stores information using rotating magnetic disks and mechanical read/write heads.

Solid-State Drive

An SSD uses flash memory and has no spinning disk or moving read/write head.

USB Flash Drive

A small portable device commonly used to transfer files between computers.

Memory Card

A small flash storage device used in cameras, smartphones, and other electronics.

Optical Storage

Uses laser technology to read and write information on CDs, DVDs, and Blu-ray discs.

Cloud Storage

Stores information on remote servers accessible through the internet.

CHAPTER 11

Primary and Secondary Storage

Primary Storage

Memory directly used during computer operations. Examples include RAM, ROM, and cache memory.

Secondary Storage

Storage used to retain information for longer periods, such as HDDs, SSDs, and flash drives.

For example, a programming application may be stored on an SSD, loaded into RAM, and executed by the processor.

CHAPTER 12

Storage Space Allocation

Storage space allocation assigns available storage capacity to files and applications.

Fixed Allocation

Reserves a specific amount of storage space in advance.

Dynamic Allocation

Assigns storage space when it is needed.

Free Space Management

  • Bitmaps
  • Free lists
  • Grouping
  • Counting

Example: 500 GB minus 100 GB of applications and 150 GB of files leaves 250 GB available.

CHAPTER 13

Disk Partitioning and Formatting

Disk Partitioning

Divides a physical storage device into separate logical sections called partitions.

Disk Formatting

Prepares a storage volume to use a particular file system.

For example, a computer may use one partition for the operating system and another for personal documents.

Important: Formatting can erase existing data. Back up important files before formatting.

CHAPTER 14

Disk Scheduling

Disk scheduling determines the order in which pending disk input/output requests are processed.

FCFS

First-Come, First-Served processes requests in their arrival order.

SSTF

Shortest Seek Time First selects the request nearest to the current disk head position.

SCAN

The disk head moves in one direction, processing requests before reversing.

C-SCAN

Processes requests in one direction before returning to the beginning.

These traditional scheduling algorithms are primarily associated with mechanical HDDs.

CHAPTER 15

File Permissions and Security

File permissions determine which operations users and applications may perform.

  • Read: View file contents.
  • Write: Modify file contents.
  • Execute: Run executable files.

Access Control

Access control uses user accounts, groups, permissions, and Access Control Lists to restrict unauthorized access.

Encryption

Encryption transforms readable information into a protected form that requires an authorized key or method to access.

CHAPTER 16

Data Backup and Recovery

Data backup creates additional copies of important information to reduce the risk of permanent data loss.

Common Backup Types

  • Full backup
  • Incremental backup
  • Differential backup

Data Recovery

Data recovery restores lost or damaged information using available backups or specialized recovery methods.

Maintaining backups in separate locations improves protection against hardware failure, accidental deletion, and other incidents.

CHAPTER 17

Disk Fragmentation and Defragmentation

Fragmentation

Fragmentation occurs when file data is stored in nonconsecutive locations on a storage device.

Defragmentation

Defragmentation reorganizes fragmented data to improve access efficiency on mechanical hard drives.

SSDs do not require traditional HDD-style defragmentation because they do not use mechanical read/write heads.

CHAPTER 18

Cloud Storage and Network Storage

Cloud Storage

Allows files to be stored on remote servers and accessed over the internet.

Network Storage

Allows computers connected to a network to access shared storage resources.

Benefits

  • File sharing
  • Collaboration
  • Centralized storage
  • Remote access
  • Additional backup options
CHAPTER 19

Storage Performance and Reliability

Storage performance describes how efficiently a device reads, writes, and retrieves data.

Performance Factors

  • Read and write speed
  • Access latency
  • Storage interface
  • Device technology
  • Workload characteristics

Reliability

Reliability refers to a storage system's ability to maintain dependable operation and preserve information.

CHAPTER 20

RAID Technology

RAID combines multiple storage drives to provide different performance or redundancy characteristics.

RAID 0

Uses striping to distribute data across drives but provides no redundancy.

RAID 1

Uses mirroring to store duplicate data on multiple drives.

RAID 5

Uses striping with distributed parity to tolerate one drive failure.

RAID is not a substitute for maintaining separate backups.

CHAPTER 21

Storage Virtualization

Storage virtualization combines or abstracts physical storage resources so they can be managed as logical storage.

Advantages

  • Centralized administration
  • Flexible allocation
  • Improved resource utilization
  • Simplified storage management

Data Integrity and Protection

Data integrity means maintaining the accuracy and consistency of stored information.

Protection Methods

  • Encryption
  • Checksums
  • Backups
  • Access controls
  • System monitoring
CHAPTER 25

Storage Capacity and Measurement

Storage capacity refers to the amount of information a storage device can hold.

Common Units

  • Bit
  • Byte
  • Kilobyte
  • Megabyte
  • Gigabyte
  • Terabyte

Decimal storage units use multiples of 1,000, while binary units such as KiB, MiB, and GiB use multiples of 1,024.

CHAPTER 28

Best Practices in File and Storage Management

  • Use descriptive file names.
  • Organize related files into folders.
  • Perform regular backups.
  • Monitor available storage capacity.
  • Remove unnecessary files carefully.
  • Apply appropriate file permissions.
  • Protect important information.
  • Maintain storage devices regularly.
CHAPTER 29

Future of File Systems and Storage Management

SSD Technology

SSDs continue to be widely adopted because of their speed and lack of moving parts.

Cloud Storage

Cloud systems support remote access, collaboration, and flexible storage capacity.

Artificial Intelligence

AI can assist with monitoring storage usage, identifying patterns, and predicting storage requirements.

Advanced File Systems

Modern file systems increasingly support snapshots, checksums, encryption, and copy-on-write techniques.

CHAPTER 30

Summary and Conclusion

File systems and storage management are essential components of modern computer systems.

File systems organize information into files and directories, maintain metadata, allocate storage space, and support access controls.

Storage management includes allocation, monitoring, protection, backup, recovery, partitioning, and performance optimization.

Understanding these technologies provides Information Technology students with a foundation for operating systems, computer maintenance, data security, and reliable information management.
