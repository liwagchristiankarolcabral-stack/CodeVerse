Introduction to Operating Systems

This part introduces the meaning, purpose, operation, basic concepts, and components of an operating system.

LESSON 01

What Is an Operating System?

An Operating System, commonly known as OS, is system software that controls and manages the overall operation of a computer.

It allows users to interact with the device and provides the necessary services for application programs to work properly.

The operating system manages different computer resources, such as the processor, memory, storage devices, and input/output devices.

It makes sure that these resources are used properly while different programs are running.

Example

When a student opens a web browser, the operating system helps load the application into memory, provides access to the internet through available network services, and allows the user to interact with the browser using a keyboard and mouse.

Examples of Operating Systems

  • Microsoft Windows: Commonly used on desktop and laptop computers.
  • macOS: Designed for Apple Mac computers.
  • Linux: Widely used in servers, computers, and other devices.
  • Android: Commonly used on smartphones and tablets.
  • iOS: Used on Apple's iPhone devices.
Remember: The operating system acts as a connection between users, application programs, and computer hardware.
LESSON 02

Purpose of an Operating System

The main purpose of an operating system is to make a computer easier to use while managing its resources efficiently.

1. Makes Computers Easier to Use

It provides an interface that allows users to open applications, manage files, and perform different activities without directly controlling hardware.

2. Manages Computer Resources

It controls how the processor, memory, storage, and other hardware components are used.

3. Runs Application Programs

It provides the environment and services required by software applications.

4. Maintains System Security

It helps protect files, user accounts, and system resources from unauthorized access.

5. Coordinates Computer Activities

It manages different tasks and allows multiple applications to operate efficiently.

Example: When a user listens to music while browsing the internet, the operating system coordinates the resources needed by both applications so they can work at the same time.
LESSON 03

How an Operating System Works

An operating system works as a connection between the user, application software, and computer hardware.

When a user performs an action, such as opening a program, the operating system receives the request and coordinates the necessary resources.

General Process

  1. The user performs an action through an input device.
  2. The application sends a request to the operating system.
  3. The operating system processes the request.
  4. The operating system communicates with the appropriate hardware through system components and device drivers.
  5. The hardware performs the requested operation.
  6. The result is presented to the user through the application.

Example: Opening a Picture

  • The user clicks the image file.
  • The operating system identifies the file type.
  • It opens the appropriate image application.
  • It loads the necessary data from storage into memory.
  • The image appears on the screen.

LESSON 04

Basic Concepts of Operating Systems

Understanding the basic concepts of an operating system helps explain how computers perform different tasks.

1. Process

A process is a program that is currently being executed by the computer.

When an application is opened, the operating system creates and manages its process.

Example: Opening Google Chrome creates one or more browser processes.

2. Memory Management

Memory management refers to how the operating system allocates and controls the computer's memory.

Example: When a user opens a video editor, the operating system provides memory for the application to work.

3. File Management

File management involves organizing, storing, retrieving, and deleting files.

Example: Creating a folder and saving a school document inside it.

4. Device Management

Device management controls the communication between the computer and connected hardware devices.

Example: Using a printer to print a document.

5. Security Management

Security management protects the system and its information through user accounts, permissions, and other security features.

LESSON 05

An operating system is made up of different components that work together to manage computer activities.

1. Kernel

The kernel is the central part of an operating system.

It manages important resources such as the CPU, memory, and devices.

2. Shell

The shell provides a way for users to communicate with the operating system.

3. File System

The file system organizes how information is stored and retrieved from storage devices.

4. Device Drivers

Summary: These components work together to make the computer function properly.
PART 02

Major Functions of an Operating System

An operating system performs several important functions that allow computer hardware and software to work together.

These functions include process management, CPU scheduling, memory management, file management, device management, security, networking, and other essential system operations.

LESSON 06

Process Management

Process management is one of the main responsibilities of an operating system.

A process is a program that is currently running. The operating system manages these processes to make sure that the CPU is shared properly among different applications.

When several applications are open, the operating system keeps track of their activities and determines which process should use the CPU.

Main Responsibilities of Process Management

  • Creating and ending processes.
  • Assigning CPU time to processes.
  • Managing communication between processes.
  • Coordinating processes that share resources.
  • Handling processes that are waiting or currently running.

Real-Life Example

A student opens Google Chrome, Microsoft Word, and a music application at the same time.

The operating system manages their processes so the student can switch between applications without manually controlling the CPU.

Key Concept: Process management allows multiple applications to operate efficiently while sharing processor resources.
LESSON 07

CPU Scheduling

CPU scheduling is the process of deciding which process should use the CPU and for how long.

Since multiple programs may need the processor, the operating system uses scheduling methods to organize their execution.

The goal of CPU scheduling is to use the processor efficiently and reduce unnecessary waiting time.

Common CPU Scheduling Algorithms

1. First Come, First Served (FCFS)

The process that arrives first gets the CPU first.

Example: If Process A arrives before Process B, Process A is scheduled first.

2. Shortest Job First (SJF)

The process with the shortest estimated execution time is selected first.

Example: A process that needs 2 milliseconds may be scheduled before one that needs 8 milliseconds.

3. Round Robin (RR)

Each process receives a small amount of CPU time called a time quantum.

After its time expires, the next process gets a turn.

Example: Three processes take turns using the CPU for a fixed time period.

4. Priority Scheduling

The operating system selects processes based on their assigned priority.

Example: A high-priority system task may be scheduled before a low-priority background task.

Comparison of CPU Scheduling Algorithms

Algorithm Selection Method
FCFS Arrival order
SJF Shortest estimated CPU burst
Round Robin Fixed CPU time quantum
Priority Scheduling Assigned process priority
Remember: CPU scheduling determines which process receives processor time.
LESSON 08

Memory Management

Memory management is the function of an operating system that controls and organizes the computer's main memory, also known as Random Access Memory (RAM).

When an application is opened, the operating system allocates memory for its instructions and data.

When the application is closed, the memory it no longer needs can be released for other programs.

Main Responsibilities of Memory Management

  • Allocating memory to running programs.
  • Releasing memory when it is no longer needed.
  • Keeping track of memory usage.
  • Preventing programs from interfering with each other's memory.
  • Managing virtual memory when necessary.

Real-Life Example

When a user opens a video editing application, the operating system assigns available memory to help the program load and process video files.

If the user opens more applications, the operating system manages memory among them.

Key Concept: Memory management ensures that applications receive the memory resources needed to operate.
LESSON 09

Virtual Memory

Virtual memory is a memory management technique that allows a computer to use storage space as an extension of its physical RAM.

It gives running programs their own virtual address spaces and allows the operating system to keep only the currently needed portions of memory in RAM.

Other portions may be stored temporarily on a storage device.

Virtual memory helps computers manage applications even when physical memory is limited.

However, using storage as a substitute for RAM is usually slower than accessing actual RAM.

Importance of Virtual Memory

  • Supports programs that need more memory than is currently available in RAM.
  • Helps isolate the memory spaces of different processes.
  • Allows the operating system to manage memory more flexibly.
  • Helps improve the use of available physical memory.

Real-Life Example

A computer has several applications open, but its RAM is becoming full.

The operating system may move some less-used memory pages to a storage area so that RAM can be used by other active tasks.

LESSON 11

File Systems

A file system is the method used by an operating system to organize and manage data on storage devices.

It determines how files and folders are named, stored, accessed, and maintained.

Different operating systems support different file systems.

1. NTFS (New Technology File System)

NTFS is commonly used by Microsoft Windows.

It supports file permissions, large storage volumes, and other management features.

2. FAT32 (File Allocation Table 32)

FAT32 is an older file system that is still supported by many devices.

It is often used for removable storage, although it has limitations on individual file size.

3. exFAT (Extended File Allocation Table)

exFAT is designed for flash storage devices and supports larger files than FAT32.

4. ext4 (Fourth Extended Filesystem)

ext4 is widely used by Linux distributions.

It supports features designed to help organize and manage files reliably.

Comparison of File Systems

File System Common Use
NTFS Windows computers
FAT32 Removable storage
exFAT Flash storage and large files
ext4 Linux systems
Example: When a user saves a document on a USB flash drive, the file system helps organize the information so the document can be located and opened later.

LESSON 14

Security and Protection

Security and protection are important functions of an operating system because they help keep the computer and its information safe.

The operating system provides features that control who can access files, applications, and other system resources.

1. User Authentication

This verifies the identity of a user through methods such as passwords or biometric authentication.

2. Access Control

This determines which users are allowed to access certain files or system resources.

3. User Permissions

Permissions specify whether a user can read, modify, execute, or delete a file.

4. System Updates

Updates can provide security improvements, bug fixes, and additional features.

5. Security Monitoring

The operating system may record system activities and identify unusual or unauthorized actions.

Real-Life Example

A computer has separate accounts for different family members.

Each user can have their own files and settings, while administrator permissions control important system changes.

Key Concept: Operating system security helps protect users, applications, files, and computer resources.

User Interface Management

The user interface is the part of an operating system that allows people to interact with a computer.

It provides different ways to give commands, open programs, access settings, and manage files.

There are two common types of user interfaces.

Examples

Main Responsibilities

  • Detecting application errors.
  • Monitoring CPU and memory usage.
  • Recording system events.
  • Reporting hardware problems.
  • Managing unexpected program behavior.
  • Supporting recovery after certain errors.

Real-Life Example

If an application stops responding, the operating system may display a message and allow the user to close the application without restarting the entire computer.

Key Concept: Error detection and system monitoring help maintain computer stability and identify potential problems.

PART 03

Types of Operating Systems

Operating systems are classified into different types according to their design, functions, and intended use.

Some operating systems are designed to manage multiple users, while others are developed for specific devices, real-time applications, or network environments.

LESSON 19

Batch Operating System

A Batch Operating System is a type of operating system that processes groups of jobs automatically without requiring continuous interaction from the user.

Jobs with similar requirements are collected into batches and executed according to a predefined sequence.

This type of operating system was commonly used in early computer systems that processed large amounts of information.

How a Batch Operating System Works

  1. Users submit jobs to the computer system.
  2. The operating system collects and organizes the jobs.
  3. Jobs are grouped into batches.
  4. The operating system executes the jobs automatically.
  5. The results are produced after processing.

Characteristics

  • Processes groups of jobs automatically.
  • Requires little or no interaction during execution.
  • Suitable for repetitive tasks.
  • Can process large amounts of information.
  • Jobs are executed according to the system's scheduling method.

Advantages

  • Reduces the need for continuous user interaction.
  • Suitable for repetitive operations.
  • Can efficiently process large workloads.
  • Allows automated job execution.

Disadvantages

  • Users may wait a long time for results.
  • Errors can be difficult to identify during processing.
  • Not suitable for interactive applications.
  • Individual jobs may experience delays.

Real-Life Example

A company processes employee payroll information at the end of every month.

The system collects employee attendance, salary information, and deductions before processing the payroll as a batch.

Key Concept: A Batch Operating System processes jobs automatically with minimal interaction during execution.
LESSON 20

Time-Sharing Operating System

A Time-Sharing Operating System allows multiple users or tasks to share the computer's processing resources.

The operating system divides CPU time into small intervals and distributes these intervals among different processes.

Because the CPU switches between tasks quickly, users experience responsive computer operation.

How Time-Sharing Works

  1. Multiple processes are ready for execution.
  2. The CPU scheduler selects a process.
  3. The selected process receives a limited amount of CPU time.
  4. When its time expires, another process may execute.
  5. The process continues until the tasks are completed.

Characteristics

  • Supports multiple users or tasks.
  • Distributes CPU time among processes.
  • Uses frequent context switching.
  • Provides interactive responses.
  • Allows processes to make progress concurrently.

Advantages

  • Supports interactive computing.
  • Allows multiple users to access a system.
  • Improves resource sharing.
  • Provides relatively quick response times.

Disadvantages

  • Requires careful CPU scheduling.
  • Context switching introduces overhead.
  • Performance may decrease under heavy workloads.
  • Shared environments require security controls.

Real-Life Example

Multiple students access a shared university computer server through separate terminals.

The operating system distributes CPU time among their active programs so they can interact with the system.

Remember: Time-sharing systems divide CPU time among tasks to support interactive operation.
LESSON 21

Multitasking Operating System

A Multitasking Operating System allows a computer to run multiple applications or tasks during overlapping periods.

It manages the execution of different processes so users can switch between programs without closing them.

Multitasking is an important feature of modern desktop and mobile operating systems.

How Multitasking Works

The operating system schedules different tasks and distributes CPU time among them.

On a single CPU core, the system may rapidly alternate between tasks. On multicore processors, some tasks can execute simultaneously.

Characteristics

  • Allows multiple applications to remain active.
  • Uses process scheduling.
  • Supports foreground and background tasks.
  • Allows users to switch between applications.
  • Manages CPU and memory resources.

Advantages

  • Improves user productivity.
  • Allows several applications to operate.
  • Supports background activities.
  • Helps make efficient use of system resources.

Disadvantages

  • Requires additional memory and processing resources.
  • Too many applications can reduce performance.
  • Resource contention may occur.
  • Requires efficient scheduling.

Real-Life Example

A student uses Microsoft Word to write a research paper while listening to music and downloading reference materials through a web browser.

The operating system manages these applications so they can continue operating during overlapping periods.

Examples of Multitasking Operating Systems

  • Microsoft Windows
  • macOS
  • Linux
  • Android
  • iOS
LESSON 22

Multiprocessing Operating System

A Multiprocessing Operating System supports the use of multiple processors or CPU cores to execute tasks.

Instead of relying on only one processing unit, the system can distribute workloads across available processors.

Multiprocessing can improve system performance and support simultaneous execution of tasks.

How Multiprocessing Works

  1. The operating system identifies available processors or CPU cores.
  2. Multiple processes or threads become ready for execution.
  3. The scheduler assigns eligible tasks to available processing resources.
  4. Tasks can execute simultaneously on different cores.
  5. The operating system coordinates resource sharing and task completion.

Characteristics

  • Supports multiple processors or CPU cores.
  • Allows simultaneous task execution.
  • Distributes workloads among processing resources.
  • Requires coordination between processors.
  • Can improve overall system throughput.

Advantages

  • Improves performance for suitable workloads.
  • Supports parallel execution.
  • Can increase system throughput.
  • Helps manage computationally intensive applications.

Disadvantages

  • Requires suitable hardware.
  • Can increase system complexity.
  • Some tasks do not benefit significantly from parallel execution.
  • Shared resources require synchronization.

Real-Life Example

A computer with a multicore processor runs a video editing application.

Different processing tasks can execute on separate CPU cores to help complete rendering operations.

Key Concept: Multiprocessing uses multiple processing resources to support simultaneous execution.
LESSON 23

Real-Time Operating System

A Real-Time Operating System, also called RTOS, is designed to respond to events within specific time requirements.

In real-time systems, producing the correct result is important, but completing the task within the required time is also essential.

Real-time operating systems are commonly used in devices that require predictable responses.

Types of Real-Time Operating Systems

1. Hard Real-Time Operating System

A hard real-time system must meet strict deadlines.

Missing a deadline may result in serious system failure.

Example: Certain industrial safety controllers must respond within a guaranteed time.

2. Soft Real-Time Operating System

A soft real-time system aims to meet timing requirements, but occasional delays may be tolerated.

Example: A multimedia application may experience a brief delay without causing complete system failure.

Characteristics

  • Designed for predictable timing.
  • Supports time-sensitive operations.
  • Uses scheduling policies suited to deadlines.
  • Commonly used in specialized devices.
  • Focuses on reliability and responsiveness.

Advantages

  • Provides predictable response times.
  • Suitable for time-critical applications.
  • Supports precise task coordination.
  • Can improve reliability in specialized systems.

Disadvantages

  • Can be complex to design.
  • Requires careful scheduling and testing.
  • May prioritize timing over general-purpose flexibility.
  • Strict timing requirements can limit design choices.

Real-Life Applications

  • Industrial automation
  • Robotics
  • Automotive control systems
  • Medical equipment
  • Embedded control devices
Remember: Real-time systems focus on meeting timing requirements, not simply completing tasks as quickly as possible.
LESSON 24

Distributed Operating System

A Distributed Operating System coordinates multiple connected computers and allows them to work together as a system.

These computers communicate through a network and may share processing tasks, information, and resources.

The goal is to coordinate distributed resources and make them easier to use.

How a Distributed Operating System Works

  1. Multiple computers are connected through a network.
  2. The system coordinates their resources.
  3. Tasks may be distributed among different computers.
  4. Computers communicate and exchange information.
  5. The results are combined or delivered to users.

LESSON 25

Network Operating System

A Network Operating System, commonly called NOS, provides services that allow computers and users to share resources through a network.

It supports functions such as file sharing, printer sharing, user account management, and network administration.

Network operating systems are commonly used in organizations where multiple computers need access to shared resources.

Main Functions

  • Managing network user accounts.
  • Providing shared file access.
  • Supporting printer sharing.
  • Managing network permissions.
  • Providing network services.
  • Supporting centralized administration.

Characteristics

  • Designed to support network services.
  • Allows connected computers to share resources.
  • Provides user and permission management.
  • Supports network communication.
  • Often used on servers.

Advantages

  • Supports centralized resource management.
  • Allows users to share files and devices.
  • Can simplify network administration.
  • Supports organization-wide services.

Disadvantages

  • Requires network infrastructure.
  • May require specialized administration.
  • Network or server failures may interrupt services.
  • Requires proper security management.

Examples

  • Windows Server
  • Linux server distributions
  • Other server operating systems providing network services

Real-Life Example

A school uses a central server to store documents and manage shared printers.

Teachers and authorized staff members can access shared resources from computers connected to the school network.

LESSON 27

System Calls and Their Functions

A system call is a mechanism that allows a program to request services from the operating system kernel.

Application programs often need to perform operations that require access to protected system resources.

Instead of accessing these resources directly, applications use system calls to request operating system services.

Purpose of System Calls

  • Provide access to operating system services.
  • Support process creation and management.
  • Allow programs to work with files.
  • Support input and output operations.
  • Enable communication between processes.
  • Help control access to protected resources.

Common Categories of System Calls

1. Process Control

Process control system calls allow programs to create, execute, and terminate processes.

Example: A program requests the operating system to create a new process.

2. File Management

File management system calls allow applications to open, read, write, and close files.

Example: A text editor requests access to a document stored on the computer.

3. Device Management

Device-related system calls allow programs to request input and output operations involving hardware devices.

4. Information Maintenance

These system calls allow programs to obtain or modify certain system information.

5. Communication

Communication system calls support the exchange of information between processes.

6. Protection

Protection-related system calls support access control and resource permissions.

LESSON 28

Booting Process and System Startup

Booting is the process of starting a computer and loading the operating system into memory.

When a computer is turned on, several operations take place before the user can access the operating system.

Steps in the Booting Process

Step 1: Power On

The user presses the computer's power button.

The hardware receives power and begins its initialization.

Step 2: Firmware Initialization

The computer's BIOS or UEFI firmware initializes important hardware components.

It also performs checks needed to prepare the computer for startup.

Step 3: Boot Device Selection

The firmware identifies a suitable boot device according to the computer's startup configuration.

Step 4: Bootloader Execution

The bootloader begins loading the operating system kernel.

Step 5: Kernel Initialization

The operating system kernel initializes essential components and prepares system resources.

Step 6: System Services

Important operating system services and background processes are started.

Step 7: Login or Desktop

The operating system displays a login screen, desktop, or another user interface.
