CSS Introduction

CSS is an important technology in web development. While HTML defines the structure of a webpage, CSS controls how that webpage looks and how its elements are arranged.

CSS allows developers to create visually appealing websites using colors, fonts, spacing, backgrounds, borders, and different layout techniques.

What is CSS?

CSS stands for Cascading Style Sheets. It is a stylesheet language used to control the presentation and appearance of HTML documents.

  • CSS controls the appearance of HTML elements.
  • CSS defines colors, fonts, spacing, and layouts.
  • CSS supports different screen sizes and devices.
  • CSS can style multiple webpages using one stylesheet.
  • External stylesheets are stored in files ending with .css.

Example of CSS

h1 {
    color: blue;
    text-align: center;
}

p {
    font-size: 18px;
    color: gray;
}

Example Explained

The h1 selector targets first-level headings. The color property changes their text color, while text-align controls text alignment.

The p selector targets paragraphs. The font-size property changes text size, while color changes the text color.

Why Use CSS?

CSS is used to define the visual design of webpages. It separates presentation rules from HTML content, making websites easier to design, update, and maintain.

Advantages of CSS

  • Consistent Design: Multiple webpages can share the same appearance.
  • Easy Maintenance: Updating one external stylesheet can change the design of many webpages.
  • Responsive Design: Websites can adapt to different screen sizes.
  • Better Organization: HTML handles content while CSS handles presentation.
  • Design Flexibility: The same HTML content can be presented using different visual styles.

CSS Styling Example

body {
    background-color: lightblue;
}

h1 {
    color: white;
    text-align: center;
}

p {
    font-family: Verdana, sans-serif;
    font-size: 20px;
}

CSS Saves Time

CSS rules are often stored in an external stylesheet. This makes it possible to update the appearance of an entire website without editing every HTML page.

Connecting External CSS

<link rel="stylesheet" href="style.css">

The link element is placed inside the HTML <head> element and connects the webpage to an external CSS file.

CSS Website Layout

A website layout describes how different parts of a webpage are organized and displayed.

A common website structure includes a header, navigation menu, content area, and footer.

Common Website Sections

  • Header: The top section of a website.
  • Navigation: Links for moving between pages.
  • Main Content: The primary information on a page.
  • Side Content: Additional information or related links.
  • Footer: Information displayed at the bottom.

Example Website Structure

<header>
    <h1>My Website</h1>
</header>

<nav>
    <a href="#">Home</a>
    <a href="#">About</a>
</nav>

<main>
    <h2>Main Content</h2>
    <p>Welcome to my website.</p>
</main>

<footer>
    <p>Copyright 2026</p>
</footer>

CSS Header

A header is usually positioned at the top of a webpage. It commonly contains a website name, logo, heading, or introductory information.

Header Styling Example

.demo-header {
    background-color: #f1f1f1;
    text-align: center;
    padding: 20px;
}

HTML Example

<header class="demo-header">
    <h1>My Header</h1>
</header>

Example Explained

  • background-color defines the header background.
  • text-align controls horizontal text alignment.
  • padding adds space inside the header.

CSS Navigation Bar

A navigation bar contains links that help visitors move between different pages or sections of a website.

HTML Example

<ul class="demo-topnav">
    <li><a href="#">Home</a></li>
    <li><a href="#">About</a></li>
    <li><a href="#">Services</a></li>
    <li><a href="#">Contact</a></li>
</ul>

CSS Example

ul.demo-topnav {
    display: flex;
    list-style-type: none;
    margin: 0;
    padding: 0;
    background-color: #333333;
}

ul.demo-topnav li a {
    display: block;
    color: white;
    padding: 14px 16px;
    text-decoration: none;
}

ul.demo-topnav li a:hover {
    background-color: #dddddd;
    color: black;
}

Example Explained

  • display: flex arranges links horizontally.
  • list-style-type: none removes list markers.
  • padding creates spacing around links.
  • :hover changes the appearance when a pointer moves over a link.

CSS Layout Content

Website content can be arranged into one or more columns depending on the available screen space.

Common Content Layouts

  • One-Column Layout: Often used for mobile screens.
  • Two-Column Layout: Commonly used for tablets and laptops.
  • Three-Column Layout: Useful for wider desktop screens.

Responsive Three-Column Example

.demo-columns {
    display: flex;
    flex-direction: row;
}

.demo-columns > div {
    flex: 1;
    margin: 10px;
    padding: 20px;
    background-color: #e8eef9;
}

@media screen and (max-width: 600px) {
    .demo-columns {
        flex-direction: column;
    }
}

HTML Example

<div class="demo-columns">
    <div>Column 1</div>
    <div>Column 2</div>
    <div>Column 3</div>
</div>

On wider screens, the columns appear next to each other. When the viewport is 600 pixels wide or less, the media query changes the layout to a vertical arrangement.

CSS Basic and Fixed Footer

A footer is generally placed at the bottom of a webpage. It often contains copyright notices, contact details, legal information, and additional navigation links.

Basic Footer

A basic footer follows the normal document layout. It appears after the content preceding it. 

.demo-footer {
    background-color: #f1f1f1;
    text-align: center;
    padding: 15px;
}

Fixed Footer

A fixed footer remains attached to the bottom of the browser viewport even while the user scrolls. 

.demo-fixed-footer {
    position: fixed;
    bottom: 0;
    left: 0;
    width: 100%;
    background-color: #f1f1f1;
    padding: 15px;
    text-align: center;
    z-index: 1000;
}

Basic Footer vs. Fixed Footer

Basic Footer Fixed Footer
Follows normal document flow Positioned relative to the viewport
Moves as the user scrolls Remains visible while scrolling
Appears after preceding content Can overlap content without additional spacing

CSS Flexbox

CSS Flexbox is a layout system that makes it easier to arrange elements inside a container.

It is particularly useful when building responsive navigation bars, rows of cards, button groups, and other flexible webpage components.

CSS Flexbox (Flexible Box Layout)

Flexbox stands for the CSS Flexible Box Layout module. It provides a flexible way to arrange items horizontally or vertically inside a container.

Flexbox simplifies responsive layouts without requiring traditional float-based positioning techniques.

Flexbox Features

  • Arranges elements in rows or columns.
  • Distributes available space between items.
  • Supports horizontal and vertical alignment.
  • Allows items to grow or shrink.
  • Can wrap items onto additional lines.

Flexbox vs. Grid

Flexbox is primarily designed for one-dimensional layouts, working along a row or a column.

CSS Grid is designed for two-dimensional layouts, where rows and columns can be controlled together.

CSS Flexbox Components

A Flexbox layout consists of a flex container and one or more flex items.

Flex Container

The flex container is the parent element. It becomes a flex container when its display property is set to flex or inline-flex. 

.flex-container {
    display: flex;
}

Flex Items

Flex items are the direct children of a flex container. The browser automatically arranges them according to the container's flex properties.

Important Flexbox Properties

Property Purpose
display Enables flex layout
flex-direction Defines the main direction of items
justify-content Aligns and distributes items along the main axis
align-items Aligns items along the cross axis
flex-wrap Controls whether items can move to another line
gap Sets spacing between flex items

A Flex Container with Three Flex Items

The following example demonstrates a flex container with three child elements.

HTML Example

<div class="demo-flex">
    <div>Item 1</div>
    <div>Item 2</div>
    <div>Item 3</div>
</div>

CSS Example

.demo-flex {
    display: flex;
    background-color: DodgerBlue;
}

.demo-flex div {
    background-color: #f1f1f1;
    margin: 10px;
    padding: 20px;
    font-size: 24px;
    color: #202b40;
}

Example Output

Item 1
Item 2
Item 3

The blue area represents the flex container. The three light-colored boxes are flex items.

CSS Grid Layout

CSS Grid is a layout system for arranging webpage elements into rows and columns.

It is useful for building complex website structures, image galleries, dashboards, and responsive content areas.

CSS Grid Layout Module

The CSS Grid Layout Module provides a two-dimensional system for positioning elements in rows and columns.

Grid allows developers to control both dimensions of a layout without relying on floats or traditional positioning techniques.

Advantages of CSS Grid

  • Creates layouts using rows and columns.
  • Supports complex webpage structures.
  • Controls spacing between grid items.
  • Allows flexible column and row sizes.
  • Supports responsive website layouts.

Grid vs. Flexbox

CSS Grid CSS Flexbox
Two-dimensional layout One-dimensional layout
Controls rows and columns together Arranges items along a main axis
Useful for page structures and dashboards Useful for navigation and component alignment

CSS Grid Components

A CSS Grid layout consists of a grid container and one or more grid items.

Grid Container

The grid container is the parent element. It is created by setting the display property to grid or inline-grid. 

.grid-container {
    display: grid;
}

Grid Items

Grid items are the direct children of the grid container. They are automatically placed into the grid according to its defined rows, columns, and placement rules.

Grid Columns

Columns are vertical tracks within the grid. Their sizes can be defined using grid-template-columns. 

.grid-container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
}

Grid Rows

Rows are horizontal tracks within the grid. Their sizes can be controlled using grid-template-rows.

Grid Gaps

The gap property controls the spacing between rows and columns. 

.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 15px;
}

A Grid Container with Five Grid Items

The following example creates a grid container with five items arranged into three columns.

HTML Example

<div class="demo-grid">
    <div>1</div>
    <div>2</div>
    <div>3</div>
    <div>4</div>
    <div>5</div>
</div>

CSS Example

.demo-grid {
    display: grid;
    grid-template-columns: auto auto auto;
    background-color: DodgerBlue;
    padding: 10px;
}

.demo-grid div {
    background-color: #f1f1f1;
    border: 1px solid black;
    padding: 15px;
    font-size: 24px;
    text-align: center;
    color: #202b40;
}

Example Output

3
4
5

The first three items occupy the first row. The remaining two items appear in the second row.

All CSS Grid Properties

CSS Grid provides properties for defining grid tracks, controlling item placement, adjusting alignment, and managing spacing.

CSS Property Description
align-content Aligns the grid tracks along the block axis when extra space is available.
align-items Sets the default block-axis alignment of grid items.
align-self Controls the block-axis alignment of an individual grid item.
display Defines the element's display type, including grid and inline-grid.
column-gap Specifies the spacing between grid columns.
gap Sets both row and column spacing.
grid Shorthand for several explicit and implicit grid properties.
grid-area Assigns a grid area name or specifies item placement boundaries.
grid-auto-columns Defines the size of implicitly created columns.
grid-auto-flow Controls how automatically placed grid items are inserted.
grid-auto-rows Defines the size of implicitly created rows.
grid-column Shorthand for grid-column-start and grid-column-end.
grid-column-end Specifies the ending grid line for a column placement.
grid-column-start Specifies the starting grid line for a column placement.
grid-row Shorthand for grid-row-start and grid-row-end.
grid-row-end Specifies the ending grid line for a row placement.
grid-row-start Specifies the starting grid line for a row placement.
grid-template Shorthand for defining explicit grid rows, columns, and areas.
grid-template-areas Defines a layout using named grid areas.
grid-template-columns Defines the number and sizes of explicit grid columns.
grid-template-rows Defines the sizes of explicit grid rows.
justify-content Aligns grid tracks along the inline axis when extra space is available.
justify-self Controls the inline-axis alignment of an individual grid item.
place-self Shorthand for align-self and justify-self.
place-content Shorthand for align-content and justify-content.
row-gap Specifies the spacing between grid rows.

Example: Using Grid Properties

.demo-dashboard {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: auto auto;
    gap: 20px;
    padding: 20px;
}

.demo-dashboard .featured {
    grid-column: 1 / 3;
}

.demo-dashboard .sidebar {
    grid-column: 3;
}

In this example, the grid contains three columns. The featured element spans the first two columns, while the sidebar occupies the third column.

18. CSS Selectors and Combinators

Selectors identify the HTML elements that receive styles. Class selectors can be reused, ID selectors target a specific identifier, and combinators describe relationships between elements.

CSS Example

.card { border-radius: 12px; }
#featured { background: #eef4ff; }
nav a { text-decoration: none; }
.card > h3 { margin-top: 0; }

Practical Guidance

Use classes for reusable components, and avoid overly complex selectors that are difficult to maintain.

19. The CSS Cascade and Specificity

When several CSS declarations target the same property, the browser resolves conflicts using cascade origin, importance, cascade layers, specificity, scoping proximity, and source order. Specificity compares selector weights.

CSS Example

.notice { color: navy; }
.notice.important { color: crimson; }
/* The second selector is more specific. */

Practical Guidance

Prefer predictable class-based styling rather than repeatedly increasing selector specificity.

20. CSS Box Model

Every CSS element has a content box surrounded by padding, border, and margin. Padding is inside the border, while margin creates space outside it.

CSS Example

.panel {
  box-sizing: border-box;
  width: 320px;
  padding: 20px;
  border: 2px solid #2458b6;
  margin: 16px auto;
}

Practical Guidance

Using border-box makes declared widths include padding and borders, simplifying responsive sizing.

21. CSS Colors, Fonts, and Typography

Colors communicate hierarchy and brand identity. Typography controls readability through font families, sizes, weights, line heights, and letter spacing.

CSS Example

.article-title {
  color: #173e83;
  font-family: Georgia, serif;
  font-size: 2rem;
  line-height: 1.25;
}
.article-body { line-height: 1.7; }

Practical Guidance

Maintain sufficient contrast and use relative font sizes where appropriate for accessibility.

22. CSS Units and Sizing

Absolute units such as px are useful for fine detail. Relative units such as rem, em, %, vw, and vh help layouts adapt to font settings and viewport dimensions.

CSS Example

.content { width: min(90%, 72rem); margin-inline: auto; }
h2 { font-size: clamp(1.5rem, 3vw, 2.5rem); }
.hero { min-height: 45vh; }

Practical Guidance

Use rem for scalable typography and percentages or flexible tracks for responsive layouts.

23. Display, Visibility, and Overflow

The display property controls how elements participate in layout. Common values include block, inline, flex, grid, and none. Overflow controls what happens when content exceeds its box.

CSS Example

.code-panel { overflow-x: auto; }
.hidden { display: none; }
.inline-label { display: inline; }

Practical Guidance

Use overflow-x: auto for wide code examples and tables on small screens.

24. CSS Positioning and Stacking

CSS position supports static, relative, absolute, fixed, and sticky positioning. Positioned elements can overlap, and z-index helps control stacking order within stacking contexts.

CSS Example

.sidebar { position: sticky; top: 1rem; }
.badge { position: absolute; top: 8px; right: 8px; }
.card { position: relative; }

Practical Guidance

A sticky sidebar can remain visible while scrolling, but it must have an appropriate top offset and sufficient scrolling space.

25. Pseudo-Classes and Pseudo-Elements

Pseudo-classes style elements in a state such as :hover, :focus-visible, or :checked. Pseudo-elements such as ::before and ::after style generated parts of an element.

CSS Example

a:hover { text-decoration: underline; }
button:focus-visible { outline: 3px solid royalblue; }
.note::before { content: "Tip: "; font-weight: bold; }

Practical Guidance

Never rely on hover alone to communicate essential information; keyboard focus should also be visible.

26. Advanced Flexbox Alignment and Wrapping

Flexbox distributes space along a main axis and aligns items on a cross axis. flex-wrap permits multiple lines; flex-grow, flex-shrink, and flex-basis determine item sizing.

CSS Example

.cards { display: flex; flex-wrap: wrap; gap: 1rem; }
.cards > article { flex: 1 1 220px; }
.toolbar { display: flex; justify-content: space-between; align-items: center; }

Practical Guidance

Use gap for consistent spacing and flex-wrap for card rows that should reflow on narrower screens.

27. Advanced Grid Placement and Named Areas

CSS Grid lets you place items using grid lines or named areas. The repeat() and minmax() functions simplify flexible track definitions, while grid-column and grid-row allow items to span tracks.

CSS Example

.dashboard {
  display: grid;
  grid-template-areas: "header header" "main aside";
  grid-template-columns: 2fr 1fr;
  gap: 1rem;
}
.dashboard-header { grid-area: header; }
.dashboard-main { grid-area: main; }
.dashboard-aside { grid-area: aside; }

Practical Guidance

Named grid areas make large page layouts easier to read and rearrange at different breakpoints.

28. Media Queries and Responsive Design

Media queries apply styles based on conditions such as viewport width and user preferences. A mobile-first approach begins with smaller screens and adds enhancements as space becomes available.

CSS Example

.gallery { display: grid; grid-template-columns: 1fr; gap: 1rem; }
@media (min-width: 700px) {
  .gallery { grid-template-columns: repeat(2, 1fr); }
}
@media (min-width: 1100px) {
  .gallery { grid-template-columns: repeat(3, 1fr); }
}

Practical Guidance

Choose breakpoints based on when content needs to change rather than targeting individual device models.

29. CSS Custom Properties and Reusable Themes

Custom properties store reusable values such as colors, spacing, and typography. They can be overridden on a parent element, allowing nested components and dark themes to inherit consistent settings.

CSS Example

:root { --surface: #ffffff; --text: #1a2943; }
.dark-mode { --surface: #172236; --text: #ecf3ff; }
.panel { background: var(--surface); color: var(--text); }

Practical Guidance

Define shared design tokens in :root and override them for dark mode rather than duplicating every component rule.

30. CSS Transitions, Transforms, and Accessibility

Transitions animate changes between property values, while transforms can translate, rotate, or scale an element. Motion should be subtle and respect user preferences.

CSS Example

.action { transition: transform 180ms ease; }
.action:hover { transform: translateY(-2px); }
@media (prefers-reduced-motion: reduce) {
  .action { transition: none; }
}

Practical Guidance

Use prefers-reduced-motion to disable nonessential animation for people who request less motion.
