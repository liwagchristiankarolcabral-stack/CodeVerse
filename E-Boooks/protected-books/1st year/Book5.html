Data, Information, Number Systems, and Computer Architecture

Computers represent, organize, process, and store information using digital signals and binary number systems. Understanding how data becomes information, how numbers are represented, and how computer hardware executes instructions is essential to studying information technology.

This lesson explores data representation, positional number systems, binary arithmetic, character encoding, logic gates, error detection, CPU architecture, memory systems, and hardware performance.

1. The DIKW Pyramid Architecture

1.1 Data vs. Information

Data refers to raw, unprocessed facts, symbols, signals, or observations that have not yet been given meaningful context.

Information is data that has been organized, processed, and interpreted to become meaningful and useful for decision-making.

1.2 The DIKW Hierarchy

                 WISDOM
             Applied Judgment
                    ▲
                KNOWLEDGE
          Understanding and Experience
                    ▲
               INFORMATION
           Processed and Organized Data
                    ▲
                   DATA
             Raw Facts and Values

1.3 Comparison

Level Description Example
Data Unprocessed facts 39.5
Information Data with context Body temperature: 39.5°C
Knowledge Information combined with understanding A high temperature may indicate fever.
Wisdom Informed judgment and decisions Seek appropriate medical assessment.

2. Data Types and Data Representation

2.1 Primitive Data Types

Primitive data types are basic categories of values supported by programming languages and computer hardware.

  • Integer: Whole numbers without fractional parts.
  • Floating-Point: Numbers represented with fractional precision.
  • Character: Letters, digits, and symbols represented numerically.
  • Boolean: Logical values TRUE and FALSE.

3. Positional Number Systems

3.1 Radix or Base

A positional number system represents numbers using digits whose values depend on their position. The number of available digit symbols is called the radix or base.

SystemBaseDigits
Binary20–1
Octal80–7
Decimal100–9
Hexadecimal160–9, A–F

3.2 Positional Expansion

Number Value = Sum of (Digit × Base^Position)

Example:

(1011)₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰
        = 8 + 0 + 2 + 1
        = (11)₁₀

4. The Decimal Number System (Base-10)

The decimal system uses ten digits, from 0 to 9. Each position represents a power of ten.

4.1 Decimal Positional Expansion

Number: 4,582

4 × 10³ = 4000
5 × 10² =  500
8 × 10¹ =   80
2 × 10⁰ =    2
----------------
Total     = 4582

Decimal is widely used in everyday calculations, financial records, measurements, and human-readable computer interfaces.

5. The Binary Number System (Base-2)

Binary uses two digits: 0 and 1. Computers use binary because digital electronic circuits can distinguish two logical states.

6. The Octal Number System (Base-8)

Octal uses digits 0 through 7. Each octal digit corresponds to exactly three binary bits.

6.1 Binary and Octal Mapping

Binary: 111 101 100
Octal:    7   5   4

Result: (111101100)₂ = (754)₈

6.2 Unix File Permissions

Unix and Linux systems use octal notation to represent file permissions. 

Read    (r) = 4
Write   (w) = 2
Execute (x) = 1

rwx = 4 + 2 + 1 = 7
r-x = 4 + 0 + 1 = 5
r-- = 4 + 0 + 0 = 4

Permission Code: 754

7. The Hexadecimal Number System (Base-16)

Hexadecimal uses sixteen symbols: 0–9 and A–F. The letters A through F represent decimal values 10 through 15.

7.1 Hexadecimal Conversion

Binary: 1111 1010
Hex:       F    A

Result: (11111010)₂ = (FA)₁₆

7.2 Applications

  • Memory addresses, such as 0x7FFF.
  • Web color codes, such as #FF5733.
  • Machine code and debugging.
  • Compact representation of binary values.

8. Algorithmic Base Conversion Procedures

8.1 Decimal to Binary

To convert a decimal integer into binary, repeatedly divide it by two and record each remainder. Read the remainders from bottom to top. 

Convert 156 to Binary

156 ÷ 2 = 78  R0
 78 ÷ 2 = 39  R0
 39 ÷ 2 = 19  R1
 19 ÷ 2 =  9  R1
  9 ÷ 2 =  4  R1
  4 ÷ 2 =  2  R0
  2 ÷ 2 =  1  R0
  1 ÷ 2 =  0  R1

Read upward: 10011100

(156)₁₀ = (10011100)₂

8.2 Binary to Decimal

Multiply each binary digit by its corresponding power of two and add the results.

9. Direct Binary, Octal, and Hexadecimal Mapping

Binary values can be converted directly into octal or hexadecimal by grouping bits.

  • Binary to Octal: Group bits in sets of three.
  • Binary to Hexadecimal: Group bits in sets of four.

9.1 Conversion Examples

Binary to Octal:

101 110 011
 5   6   3

Result: (563)₈


Binary to Hexadecimal:

1010 1111
  A    F

Result: (AF)₁₆

10. Signed Binary Number Encodings

Signed binary representations allow computers to store both positive and negative integers.

10.1 Sign-Magnitude

The most significant bit indicates the sign, while the remaining bits store the magnitude.

10.2 One's Complement

Negative values are created by inverting every bit of the positive representation.

10.3 Two's Complement

Two's complement represents negative integers by inverting the bits and adding one. 

Represent -5 using 8 bits

+5 = 00000101

Invert:
     11111010

Add 1:
     11111011

-5 = 11111011

Subtraction can be implemented using two's complement addition.

Signed overflow occurs when a result exceeds the range representable by the selected number of bits.

14. Digital Multimedia Data Representation

14.1 Digital Images

Raster images consist of pixels arranged in a two-dimensional grid. Each pixel stores color information.

In 24-bit RGB color, each pixel contains eight bits for red, eight for green, and eight for blue.

14.2 Digital Audio

Pulse Code Modulation converts analog sound waves into digital values through sampling and quantization.

  • Sampling measures signal amplitude at regular intervals.
  • Quantization assigns measurements to discrete levels.
  • CD audio commonly uses 44.1 kHz sampling and 16-bit resolution.

16. Error Detection and Correction Codes

Error detection and correction mechanisms help maintain data integrity during transmission and storage.

16.1 Parity Bits

A parity bit is added to make the number of binary ones either even or odd.

16.2 Hamming Code

Hamming codes use redundant check bits to locate and correct certain bit errors. Extended Hamming codes can provide single-error correction and double-error detection (SECDED).

16.3 Cyclic Redundancy Check

CRC uses polynomial division to generate a check value for detecting errors, particularly burst errors.

17. Data Storage and Hardware Layout

17.1 Endianness

Endianness determines the order in which bytes of a multi-byte value are stored in memory. 

Value: 0x12345678

Address:       00   01   02   03

Big-Endian:    12   34   56   78

Little-Endian: 78   56   34   12

17.2 Memory Alignment

Memory alignment places data at suitable address boundaries to support efficient hardware access.

Part II: Computer Architecture

Computer architecture defines the structural organization and operational behavior of computer hardware, including processors, memory systems, buses, input/output controllers, and execution mechanisms.

18. Computer System Architecture Foundations

18.1 Von Neumann Architecture

Von Neumann architecture stores program instructions and data within a shared memory system.

18.2 Harvard Architecture

Harvard architecture uses separate instruction and data memory paths, allowing concurrent access.

Von NeumannHarvard
Shared instruction and data memory Separate instruction and data memories
Shared memory path Separate memory paths
Simpler organization More specialized organization

19. The Central Processing Unit (CPU)

The CPU executes program instructions and coordinates computer operations.

  • Control Unit: Directs instruction execution.
  • ALU: Performs arithmetic and logical operations.
  • Registers: Provide high-speed internal storage.

20. Instruction Set Architecture (ISA)

An ISA defines the instructions and programmer-visible behavior supported by a processor.

20.1 CISC

Complex Instruction Set Computer architectures provide instructions capable of performing relatively complex operations.

20.2 RISC

Reduced Instruction Set Computer architectures emphasize simpler instructions and efficient execution.

CISCRISC
Complex instruction capabilities Simpler instruction design
Examples: x86, x86-64 Examples: ARM, RISC-V

21. The Instruction Execution Cycle

A classical five-stage instruction pipeline includes the following stages:

  1. Fetch: Retrieve the instruction.
  2. Decode: Interpret the instruction.
  3. Execute: Perform the operation.
  4. Memory Access: Read or write memory when required.
  5. Writeback: Store the result.
FETCH → DECODE → EXECUTE → MEMORY → WRITEBACK

22. Arithmetic Logic Unit (ALU) Design

ALUs use digital logic circuits, adders, and multiplexers to perform arithmetic and logical operations.

22.1 Condition Flags

  • Zero: Result equals zero.
  • Sign: Result is negative.
  • Carry: Unsigned carry-out occurs.
  • Overflow: Signed result exceeds its range.

23. Control Unit Implementation

23.1 Hardwired Control

Hardwired control units generate control signals using fixed logic circuits.

23.2 Microprogrammed Control

Microprogrammed control units use microinstructions to implement processor control operations.

25. CPU Pipelining and Hazard Management

Pipelining overlaps different stages of multiple instructions to improve processor throughput.

25.1 Pipeline Hazards

  • Structural: Hardware resource conflicts.
  • Data: Dependencies between instructions.
  • Control: Branches change instruction flow.

Forwarding, stalls, and branch prediction help reduce pipeline disruptions.

27. Cache Memory Mapping and Replacement

27.1 Cache Mapping

  • Direct-Mapped: Each block maps to one cache line.
  • Fully Associative: A block can occupy any cache line.
  • Set-Associative: A block maps to a set containing multiple possible lines.

27.2 Replacement Policies

  • Least Recently Used (LRU)
  • First-In, First-Out (FIFO)
  • Random Replacement

29. Input/Output Control Architectures

29.1 Programmed I/O

The CPU repeatedly checks device status while waiting for an operation.

29.2 Interrupt-Driven I/O

A device notifies the processor when attention is required.

29.3 Direct Memory Access

DMA transfers data between memory and peripherals without CPU handling every individual transfer.

30. System Bus Architecture

  • Data Bus: Transfers data.
  • Address Bus: Identifies target locations.
  • Control Bus: Carries control signals.

32. Graphics Processing Units and Accelerators

CPUs emphasize flexible execution and low-latency processing, while GPUs are designed for high-throughput parallel computations.

GPUs are widely used in graphics rendering, scientific computation, and artificial intelligence.

33. Power and Thermal Dynamics

Modern processors manage electrical power consumption and heat generation using techniques such as Dynamic Voltage and Frequency Scaling (DVFS).

DVFS adjusts operating voltage and frequency to balance performance and energy consumption.

Conclusion

Data representation and computer architecture work together to make modern computing possible. Binary encoding enables digital information processing, while processors, memory, and interconnects execute the operations required by software applications.
